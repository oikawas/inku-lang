# マニュアル改訂履歴

この履歴は`manual/`配下の利用・運用文書の改訂を記録します。製品機能そのものの詳細な変更履歴は`SPEC.ja.md`を参照してください。

## 2026-08-17 — v2.13.34未リリース基準（Web Build 921）

版を名乗る13箇所をv2.13.34／Build 921へ更新しました。**履歴帯に添える情報を読み手が選べるようになったこと、履歴の検索が全長のrender hashを取るようになったこと、AI推敲で選んだモデルが描画にも効くようになったことを書き足しました。**

- **履歴帯のサムネイルの下に添える情報を、`設定`の`その他`で選べます。** 世代・モデル・engineバージョン・ファイル容量の4つから最大2つで、**何も選ばなければ絵だけが並びます**。3つ目を選ぼうとすると既存の選択は追い出されず、上限が示されます。**`画像の作成方法`§14と§18に書き足しました。**
- **ファイル容量はサーバーが報告する保存済み作品の容量です。** 帯を埋める一覧は絵そのものを運ばないので、届いたものを数えると全部の作品が0と出ます。
- **履歴管理の検索が、全長のrender hashを受け付けます。** それまでは4文字ちょうどしかハッシュと認めていませんでした。下位4桁は従来どおりです。**`画像の作成方法`§14と`アプリケーションのインストール方法`§12に書き足しました。**
- **AI Visionによる自動推敲で選んだモデルが、観察だけでなく各世代の描画にも使われます。** それまで選択は助言の1呼び出しにしか届いていませんでした。**`画像の作成方法`§9に書き足しました。**
- **空のキャンバスの絵を、山・水・月の三筆へ描き直しました。** 画面の見た目だけの変更で、操作も設定も変わりません。

## 2026-08-16 — v2.13.33未リリース基準（Web Build 920）

版を名乗る13箇所をv2.13.33／Build 920へ更新しました。**サムネイルを焼くときに質感を塊へ畳むようになったことを書き足しました。**

- **サムネイルの幅（256pxとhidpiの512px）で焼くときは、同じ道具で続けて引かれた痕の質感を塊ひとつへ畳んでから焼きます。** 掛かる回数は減りますが掛かる面積は増えるので、得になるのは幅が小さいあいだだけで、PNG書き出しの既定2160pxやブラウザの表示幅では畳みません。**`サーバー設定方法`§3.1に書き足しました。**
- **保存されているSVGは1バイトも変わりません。** 畳むのは焼くときだけなので、作品の同一性も描画エンジンの版も動きません。
- **⚠ 既に焼かれているサムネイルは焼き直されません。** 陳腐化の判定は保存済みSVGのhashで行っており、そのSVGが動かないためです。速くなるのはこれから焼くぶんと、管理UIからの明示的な再作成だけです。

## 2026-08-16 — v2.13.32未リリース基準（Web Build 919）

版を名乗る13箇所をv2.13.32／Build 919へ更新しました。**上げた制限値が実際に紙まで届くようになったことと、総量の欄がその本数の重さを名乗るようになったことを書き足しました。**

- **上げた値が紙まで届きます。** 数を述べない記述の展開の本数は`max_expanded_primitives`に従い、群れとして見せるときの濃さと群の数の境界は`represented_count_max`に対する比で決まります。群を何個に分けるかの上端も同じ比で動くので、上限を上げても1つの群が抱える墨の数はおおよそ保たれます。**既定の設定では、これらはどれも従来と同じ値です。****`サーバー設定方法`§5.1に書き足しました。**
- **`実際に描かれる数`の欄が、その本数がおよそ何メガバイトかを添えて表示します。** 1本あたりのバイトはサーバーが測った値で、細い筆致と太い筆致の幅で示します（既定の400本でおよそ5.2〜6.5MB）。**ほかの八つの欄には出ません** —— 指示ごとの上限、可読性の閾値、打ち間違いの番人であって、ファイルの大きさを決めていないからです。
- **秒は出していません。** 今回の計測はCLI往復の実時間で、描画そのものの時間ではありません。
