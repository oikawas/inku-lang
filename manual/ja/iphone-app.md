# iPhone アプリの使い方

iPhone 版の inku は、保存した作品が並ぶホームから開きます。短い記述で描く、作品をめくって見る、画像を共有するといった操作をホームから始められます。

## ホーム

- 「すべて」と「スター」で、全作品とスターを付けた作品を切り替えます。作品を押すと、見る画面が開きます。
- 上の「⋯」には、作品の「選択」、並べ方、まとめ方、表示形式、ごみ箱、作品パックの取り込み、「更新」があります。
- 作品の並びを下へ引くと検索欄が出ます。設定は右上の歯車から開きます。

## 描く

1. ホームの「描く」を押し、記述を書きます。複数行を入力でき、欄の下に音数の目安が出ます。
2. 「描画する」を押すと、「描くときのデフォルト」の記述用の条件で新しい作品を描きます。「詳しく描く」を押すと、書いた記述が制作の頁に入ります。
3. 待つ頁で「記述 → 指示書 → 楽譜 → 画」の進みを見られます。戻っても描画は続きます。ホームなどに出る進みの行を押すと待つ頁へ戻れます。描画を止めるには「停止」を押します。
4. 作品が保存されると、待つ頁で画が組み上がり、見る画面へ移るときに触覚で知らせます。組み上がりの途中で画を押すと、組み上がりを飛ばして見る画面へ移ります。準備が間に合わない場合や、設定で「描画の動きを見せる」をオフにしている場合は一度に表示します。別の画面で待っているときは「描き上がりました」の帯の「見る」から開けます。アプリの外では、許可していれば iOS の通知で知らせます。

保存できたとき、ホームの記述欄に描き始めの文が残っていれば空になります。途中で書き直した文は残ります。失敗、停止、確かめ待ちで終わったときも記述は残ります。

写真から描くときは、ホームのカメラを押して撮影します。撮った写真は「描くときのデフォルト」の「画像」の条件で描きます。

## 見る

- 拡大していないときは、左右に払って作品をめくり、下へ払って閉じられます。ピンチで拡大します。画を一度押すと操作の表示を切り替えます。3D が使えるときは、画を 2 回押すと 3D 表示になります。
- 下の操作からスターを付けたり、「推敲する」や「共有」を選んだりできます。
- 「⋯」から作品情報とコメント、系譜、「制作で開く」、「書き出す」、詞書の設定、ごみ箱などの操作を開けます。コメントの「保存」は作品情報のコメント欄の下にあります。

## 共有

見る画面で「共有」を押すと、作品の共有カードを画像にして iOS の共有シートを開きます。LINE など、共有シートに出る送り先を選びます。

## 作品パックを取り込む

1. **Mac から**。作品を選び、「書き出す」から「作品パックに書き出す」で `.inkupack` を保存します。そのファイルを AirDrop で iPhone に送ります。
2. **Web から**。iPhone の Chrome で inku を開き、「書き出す」から「作品パックに書き出す」でファイルをダウンロードします。
3. 受け取ったファイルを inku で開きます。「ファイル」に保存して、ホームの「⋯」→「作品パックを取り込む」から選ぶこともできます。プレビューと件数を見て「取り込む」を押します。描画中は描き終わるまで待ちます。

同じ作品は飛ばし、取り込み先のスターやコメントを保ちます。取り込んだ作品は見る、共有する、スターを付けることができます。作品パックには保存条件を持つ元の描画の実行記録が入っていません。取り込んだ作品では、「記述を変える」など、保存条件が必要な推敲の項は押せません。

## 設定

- 「表示と操作」で「文字サイズ」と「描画中のマスコット」を選べます。「描画の動きを見せる」は既定でオンです。オフにすると、描画中のマスコットが止まり、待つ頁の過程の行と完成した画が一度に出ます。
- ChatGPT のプランで描くときは「ChatGPT でサインイン」を開きます。「モデル設定」で接続やモデルを設定し、「描くときのデフォルト」の「記述」「画像」で使うモデルや条件を選びます。
- 「DB設定」でバックアップを保存したり、自動バックアップを設定したりできます。DB バックアップは作品・系譜・作業状態の復元に使います。接続設定と API キーは別に管理されます。

## 制作の頁

描く欄の「詳しく描く」、または見る画面の「⋯」の「制作で開く」から進みます。記述や指示書の編集、描画条件、系譜など、Mac と共通の制作機能を iPhone の画面に合わせて使えます。操作の考え方は [画像の作成方法](./image-creation.md) を参照してください。
