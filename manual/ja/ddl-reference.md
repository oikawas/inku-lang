# DDL 文法・歳時記リファレンス

DDL（Drawing Description Language）は、形、道具、置き場所と、それらの関係を文章の形で書く言語である。この章は、人が直接書く場合にも、AI が DDL を出力する場合にも使えるよう、文の組み立てから個々の受理形までを説明する。日本語を正本とし、[英語版](../en/ddl-reference.md)は同じ意味を英語の構文で説明する。

本章が扱うのは **可視 DDL** である。自由な記述を DDL へ解釈する段階と、DDL をコンパイラが読む段階は異なる。自由記述で「夕暮れのように」と書けても、その表現がそのまま DDL の修飾語になるわけではない。DDL から描く場合は、受理済みの語と構文で意味を完結させる。

記述の意味は [SPEC.ja.md](../../SPEC.ja.md)、語形は共有 core の[歳時記](../../core/crates/inku-ddl/assets/saijiki-v2.json)、数と句の結び方は[パーサー](../../core/crates/inku-ddl/src/parser.rs)および[共有文法](../../core/crates/inku-pipeline/src/prompts.rs)に従う。本章の基準ソースは `97b50a52367554a94e9f364b90dc538d0f6b68bc`。後述する「受理」は、このソースの文法・実装上の条件を指す。実際の個数は作品の資源制限、色は作品の配色条件にも従う。

## 1. 文法の原則

### 1.1 まず、何をどう置くかを書く

単独図形の基本形は次のとおり。角括弧は任意の部分を表し、DDL へは書かない。

```text
[位置句] [修飾句] 図形を [配置方向] [数量句] 動作。
```

たとえば、`中心に`が位置、`赤い`が修飾、`円`が図形、`一つ`が数量、`置く`が動作になる。ひとつの図形を作る文には、まず図形の名と動作を確保する。色・道具・太さ・面の語だけでは、描く対象にならない。

英語は動作を先に書く。

```text
<action> [quantity] [modifiers] <shape> [line-up direction] [position] [relation].
```

### 1.2 修飾は、修飾される図形へ結ぶ

日本語の名詞修飾は `の` でつなぎ、形容詞は受理済みの形容形を使う。修飾句は図形の直前までであり、図形そのものを含まない。

| 役割 | 修飾句の例 | 続く図形 |
|---|---|---|
| 色・道具・連続性・面 | `赤いペンの実線の空の` | `円` |
| 色・道具・面 | `青いクレヨンの塗りの` | `四角` |
| 揺らぎ・色・太さ | `細かく揺れる黒い細い` | `線` |

`赤い`・`青い`・`白い`・`黒い`は色の形容形である。その他の色も、`灰の`・`黄の`・`橙の`・`紫の`・`緑の`のように名詞で結べる。語をつないだだけで新しい語を作らず、歳時記にある表面形を使う。

英語は `red pen solid empty circle` のように属性を図形の前へまとめる。数値寸法・数値回転には、図形の後ろに置く専用の構文もある。

### 1.3 語の一覧は、自由な組み合わせを保証しない

語には役割がある。`半円`は弧の形を決める語であり、単独の図形名ではない。`刷毛目`は閉じた形の面を言い、線の面には使えない。`始点`・`終点`・`途中`は、接続の対象側を選ぶ構文で使う。

DDL は未知の同義語や曖昧な所有先を推測しない。`美しく`・`寄り添う`・`ランダムに`などを DDL の属性として足すと、自由記述の解釈とは異なり、未受理の語句になる。意図を、色・形・位置・揺らぎ・有限の関係へ書き分ける。

### 1.4 省略と、明示した普通の値を分ける

`普通の大きさ`を明示した場合と、大きさを何も書かなかった場合は、同じ入力ではない。道具・色・面・位置なども、書かなければ意味の上では未指定のまま残る。パーサーが勝手にペンや黒を文章へ補うことはない。

描画時には、受理した未指定項目を共通規則で解決する。たとえば道具の省略はペン、連続性の省略は実線、閉じた形の面の省略は塗りになる。色の省略は、その作品で実際に使う背景と、黒・白の明度差を比べ、大きい側を選ぶ。同差は黒。木炭地・メゾチントでは、その地が背景の上に見せる色と比べる。したがって「色を省略すれば必ず黒」とはならない。

### 1.5 文順には意味がある

独立した命令は記述順に並ぶ。`前の形`はその前に書かれた対象を参照し、色列は各配置の先頭から始まる。文を並べ替えると、参照先・描画順・配置の種が変わりうる。

一方、対象を一意に特定できる `円は赤い。` のような主語継続は、既存の円へ属性を加える。新しい円を作る文とは区別する。詳しくは [3.3](#33-主語継続同じ対象へ後から指定する) を参照。

### 1.6 通常環境と、登録依存の語を分ける

円・線・色・地などのコア語は、プラグインの登録なしで使える。`Nature.若葉` のような名前は、登録された定義または作品・DDL 書き出しが持つ定義を必要とする。名前を知っているだけでは使えない。本章の標準例は、プラグインなしのコア DDL として読む。

## 2. 簡単な例から書く

以下は共有 core の既存成功例にある形である。日本語例と英語例は、それぞれ該当言語の DDL として入力する。説明文やコードフェンスは入力に含めない。

### 2.1 円をひとつ置く

```ddl-ja
赤い円を中心に置く。
```

```ddl-en
place one red circle at center.
```

日本語例は個数を省略しており、置く図形を1個に解決する。`中心`は中央の領域を指す。正確な一点 `(0.5, 0.5)` を指したい場合は、次の数値位置を使う。

### 2.2 大きさと位置を数で決める

```ddl-ja
画面の横0.5、縦0.5の位置に、半径0.1の赤い円を1個置く。
```

```ddl-en
place one red circle radius 0.1 at horizontal 0.5, vertical 0.5.
```

横・縦は、それぞれ画面の幅・高さに対する割合。半径は画面の短辺に対する割合である。

### 2.3 道具と太さを指定する

```ddl-ja
細い三本の黒い線を引く。
```

```ddl-en
draw three thin black lines.
```

細い黒い線を3本引く。`thin`は痕の太さであり、道具の種類とは別の指定である。

### 2.4 赤と灰を交互にする

```ddl-ja
赤と灰を交互にして、円を五つ並べる。
```

```ddl-en
Line up five circles, alternating red and gray.
```

配置の総数は5。色は赤・灰・赤・灰・赤になる。「2色あるから各5個」にはならない。

### 2.5 図形の内側を点で埋める

```ddl-ja
下に、直径0.5の円を三つの赤い点で埋める。
```

```ddl-en
fill a circle diameter 0.5 at the bottom with 3 red points.
```

円は埋める領域、点は埋めるための痕である。点を3個置き、その痕を円の輪郭で切り取る。円の塗りを赤にする指定とは異なる。

## 3. 文法リファレンス

### 3.1 言語・大文字小文字・句読点

DDL の言語は `ja` または `en`。アプリケーションが `auto` を選ぶ場合、ひらがな・カタカナ・漢字があれば日本語を優先し、それらがなく ASCII 英字があれば英語とする。それもなければ有効な言語設定へ戻り、最後の既定は日本語。これは文章の言語を選ぶ規則であり、ひとつの文の中で日英語彙を自由に混ぜる規則ではない。

英語のコア語と文法語は ASCII の大文字小文字を区別しない。`Place`・`place`、`THE BACKGROUND WITH`・`the background with`は同じように読める。プラグインの名前は別の識別子であり、この規則を当てはめない。

句点 `。`・ピリオド `.`・改行は句の境界になる。`!`・`?`と全角の対応文字も文末として読む。数値の小数点とプラグイン名のドットは、その語の内部として保持される。読点 `、`・カンマ `,`・中黒 `・`は句を読みやすくするが、所有先や参照を自由に変える記号ではない。

**ひとつの命令を途中で改行しない**書き方を推奨する。複数の命令は句点で閉じ、その後に改行する。括弧はブロックや命令の入れ子を作らない。数値範囲の注記と、名詞句で表す組は、それぞれ専用構文を使う。

### 3.2 単独図形、修飾、個数の結び方

日本語では、位置句を前に出しても図形の後ろへ置いても、所有先が一つに決まる受理形なら同じ対象へ結べる。まずは次の骨格を使う。

```text
<位置>に、<修飾句><図形>を<数量句><動作>。
<修飾句><図形>を<位置>に<動作>。
```

修飾句には、色、道具、連続性、向き、面、さばき、きめ、下塗り、揺らぎ、比率、大小、太さ、正形・辺数を置く。ひとつの語がどの図形に掛かるかを明瞭にする。

数は後置の `円を四つ置く` と、前置の `四つの円を置く` の両方を使える。前置の修飾は、完結した数量句の前後に置ける。

```ddl-ja
大きな四つの赤い円を置く。
```

これは `四つの大きな赤い円を置く。`、`赤い大きな四つの円を置く。`、`大きな赤い円を四つ置く。`と同じ所有関係になる。助数詞が既にある数量句へ、もう一つ助数詞を足さない。

数値寸法の前後にも修飾を置ける。

```ddl-ja
赤い太筆の長さ0.6の線を1本引く。
```

`長さ0.6の赤い太筆の線を1本引く。`と同じ意味である。ただし、別の図形名を越えて修飾は移らない。`赤い円の長さ0.6の線`を、赤い線の標準表記として使わない。

### 3.3 主語継続：同じ対象へ後から指定する

```ddl-ja
円を中心に置く。円は赤い。
```

第二文は新しい円を作らず、第一文の円を赤くする。対象の図形名を `は` または `が` で再導入し、受理済みの属性・動作を続ける。英語では `the`を伴う対応した名詞句を使う。

```ddl-en
place a circle at center. the circle red.
```

継続が成立するのは、対象候補が一つで、句の境界と述語の所有先が明瞭な場合だけ。次のような場合は推測しない。

| 状況 | 結果 |
|---|---|
| 先行する線がないのに `線は細かく揺れる。` | 対象なし |
| 独立した線を二つ導入した後の `線は…` | 複数候補で曖昧 |
| 間に未受理の文があり、継続境界を確定できない | 境界の診断 |
| 同じ項目に異なる指定を継続する | 衝突の診断 |
| 新規対象の並列と `the` による継続を一つの所有範囲で混ぜる | 所有関係の診断 |

コンパイラは「一番近い線」「最後の円」を選ぶ方式ではない。複数対象がある文書では、必要な属性を導入文へまとめるほうが確実である。`前の形`による関係参照は、この主語継続とは別の構文である。

### 3.4 数量

| 書き方 | 例・範囲 |
|---|---|
| 半角整数 | `1個`・`12本`・`233本` |
| 全角整数（日本語） | `９つ` |
| 漢数字（日本語） | `三本`・`十個`・`二百三十三本` |
| ひらがなの数 | `ひとつ`・`ふたつ`・`みっつ`・`よっつ`・`いつつ`・`むっつ`・`ななつ`・`やっつ`・`ここのつ`・`とお` |
| 助数詞 | `本`・`個`・`枚`、および1〜9の `つ` |
| 英語の整数 | `3`・`12`、`one`〜`nineteen`、`twenty-one`、`one hundred and five`など999までの有限な基数表現 |

日本語の `10つ`・`11つ`は個数として採用しない。十個は `10`・`十`・`とお`、または `10個`・`十個`とする。整数の表記を変えても個数の意味は変わらない。負数、小数、分数は個数として使わない。0を明示した描画命令は、ゼロ個の成功命令にはならず診断される。

`少し`・`数個`・`いくつか`・`たくさん`・`多数`・`無数`、英語の `a few`・`several`・`many`・`numerous`・`countless`には数量語としての字句認識があるが、直接 DDL の確定個数とはならない。描く個数を決めるときは整数を書く。

個数省略時の解決は動作と構造で異なる。

| 命令の構造 | 省略時 |
|---|---|
| 単独図形の置く・引く | 1個／1本 |
| 単独図形の並べる・散らす・敷き詰める | 8個／8本 |
| 複数 member をまとめて置く・並べる | 省略した各 member が1個 |
| 複数 member を散らす・敷き詰める | 明示分を保ち、合計8までの残りを省略 member へ均等配分。余りは記述順。各省略 member は最低1個 |
| 埋める | 対象領域の面積と痕の代表寸法から決める。8固定ではない |
| 個数を受けるプラグイン語 | その定義の宣言に従う |

資源制限を超える数も、元の DDL と意味には要求値を保持する。単独 primitive は安全に実行できる記述順の部分を描き、実行数と省略理由を診断する。組・プラグインなど部分実行で構造が壊れる単位は、外側の配置を省略することがある。巨大な数を別の代表数へ黙って置換する言語規則ではない。

### 3.5 図形と、有限な形修飾

通常の描画 head は、円、楕円、三角、四角、線、弧、自由線、点、雲形。`多角形`も direct DDL の有限な head として読み、歳時記の通常表示には出ない。`三角形`、`四角形`、`長方形`、英語の `rectangle`など、明示された parser 別形は後の語彙表に記す。

| 形の指定 | 意味・境界 |
|---|---|
| `正形` / `regular` | 三角・四角・多角形へ正則性を指定する有限修飾 |
| `正三角形` / `equilateral triangle` | 正三角形。数値寸法は一辺で指定 |
| `正方形`・`正四角形` / `regular square` | 正方形。明示幅と高さが異なれば不成立 |
| `五角形`〜`八角形` / `pentagon`〜`octagon` | 正多角形。辺数5〜8 |
| `辺数5の多角形` / `polygon`と`sides 5` | 辺数の有限指定。現行は5〜8、未指定は5 |
| `縦長`・`縦に長い`・`細長い` / `tall` | 三角・四角・楕円・雲形の縦長比率 |
| `横長`・`横に長い` / `wide` | 同じ4形の横長比率 |

縦長・横長は、寸法省略時の長辺:短辺が2:1。数値幅・高さを併記すると、その値を保って大小関係を確認する。`縦長`なのに幅が高さ以上なら不成立。正形との併記も不成立となる。円を縦長にして楕円へ変える、といった primitive の読み替えはしない。

自由線は、線と同じく始点と終点を持ち、その間の道筋を演奏が決める。点列・SVG path・任意の制御点を DDL へ書く構文ではない。同じ条件と種なら同じ道筋になる。形の決まった円弧を表す場合は弧を使う。

### 3.6 太さと、図形の大小

太さは道具とは別の修飾である。

| 日本語 | 英語 |
|---|---|
| ごく細い | extra-fine |
| 細い | thin |
| 太い | thick |
| ごく太い | extra-thick |

`太筆`は道具の名、`太い`はその道具で残す痕の太さ。`薄い`は濃さであり、線を細くする語ではない。

図形の大小は歳時記カテゴリではなく、次の有限な core 修飾である。倍率は、個数に依存しない通常寸法への倍率。

| 日本語の受理形 | 英語 | 倍率 |
|---|---|---|
| とても小さな・とても小さい | very small | 3/8 |
| 小さな・小さい | small | 1/2 |
| 小さめ | slightly small | 3/4 |
| 普通の大きさ | normal-sized | 1 |
| 大きめ | slightly large | 5/4 |
| 大きな・大きい | large | 3/2 |
| とても大きな・とても大きい | very large | 7/4 |
| 特大の | extra-large | 2 |
| 巨大な | huge | 8/3 |

線・自由線は長さ、通常の弧は弦長と矢高を相似に、点は直径を拡縮する。大きな数を足しても個々の形は自動では小さくならない。収まりのために個数や寸法を推測で変更しない。

**寸法を複数指定する場合の回復:** 数値寸法・大小・全幅／半幅を重ねると、それぞれを独立した寸法候補として保持し、`ConflictingSizeSpecifications`を報告する。現行実装は代表寸法の小さい候補にそろえて描く。`small`を明示半径へ掛け算する意味ではない。意図を一つに決めたいときは、寸法の指定を一つにする。

### 3.7 数値寸法

寸法の単位は画面の短辺。短辺が1,000ピクセルなら `半径0.1`は100ピクセル相当である。描く紙（画面形式）と書き出し解像度はアプリケーション側で選ぶ。DDL は、組んだときの比だけを「画面比W:H。」で宣言する（[3.27](#327-画面比組んだ比を宣言する)）。

| 対象 | 日本語 | 英語 |
|---|---|---|
| 円・点 | `半径N` / `直径N` | `radius N` / `diameter N` |
| 楕円・雲形 | `幅W、高さH` | `width W, height H` |
| 四角・通常の三角 | `幅W、高さH` | `width W, height H` |
| 四角・正三角形 | `一辺N` | `side length N` |
| 多角形 | `半径N` / `直径N`（外接円） | `radius N` / `diameter N` |
| 線・自由線 | `長さN` | `length N` |
| 通常の弧 | `弦長C、矢高S` | `chord C, sagitta S` |

日本語は `半径0.1の円`、`幅0.3、高さ0.2の四角`のように図形へ結ぶ。英語は `circle radius 0.1`のように図形の後ろへ書ける。二つ組の寸法は両方を記す。幅だけ、高さだけ、弦長だけでは完結しない。

通常の弧の矢高は、弦の中点から弧までのふくらみであり、正値かつ弦長の半分以下とする。円の半径から弧の弦長を自動推測する構文はない。

寸法は正の整数・10進小数を使う。`px`・`mm`・`%`・指数表記を付けない。小数は元の表記を保持して正確な10進数として読み、最終描画境界で数値へ変換する。数値範囲で使える `1/3` のような分数を、そのまま寸法の一般構文へ広げない。

寸法省略時の主な通常値は次のとおり。

| 対象 | 通常寸法（短辺=1） |
|---|---|
| 円、四角、通常の三角、多角形 | 直径・一辺・幅の基準 6/25 = 0.24 |
| 楕円、雲形 | 幅0.24、高さ0.144（5:3） |
| 線 | 長さ0.24 |
| 自由線 | 長さ11/20 = 0.55 |
| 弧 | 弦長0.24、矢高0.06 |
| 点 | 直径3/250 = 0.012 |

### 3.8 位置：名前、数値一点、数値範囲

位置には三つの異なる書き方がある。

| 指定 | 使う構文 | 意味 |
|---|---|---|
| 名前 | `中心に`・`上に`・`左端に`など | 定義された領域 |
| 数値一点 | `画面の横X、縦Yの位置に` | 正確な基準点 |
| 数値範囲 | `画面の横a〜b、縦c〜dの範囲に` | 配置または充填のための領域 |

横は左0→右1、縦は上0→下1。数値位置の横と縦は両方を書く。英語は `at horizontal X, vertical Y`。数値一点は画面の幅・高さを別々の1として測るため、寸法の短辺単位と混同しない。

| 名前 | 横の範囲 | 縦の範囲 |
|---|---|---|
| 上 / top | 0〜1 | 0〜1/3 |
| 下 / bottom | 0〜1 | 2/3〜1 |
| 中心 / center | 1/3〜2/3 | 1/3〜2/3 |
| 左端 / left-edge | 0〜1/10 | 0〜1 |
| 右端 / right-edge | 9/10〜1 | 0〜1 |
| 上端 / top-edge | 0〜1 | 0〜1/10 |
| 下端 / bottom-edge | 0〜1 | 9/10〜1 |
| 隅 / corner | 四隅のうち一つ。各辺の1/5の領域 | 構図の種で隅を決める |

ひとつの形を置く位置は、名前の領域を中心のまわりに2/3へ縮めた中から演奏が選ぶ。`中心`は `(0.5,0.5)` 固定ではない。位置省略の置く・引くも、中央領域を縮めた横・縦 `7/18〜11/18` を使う。2個以上の散らす・並べると、敷き詰めるの位置省略は、画面全体を使う。1個だけの散らす・並べるは置くとして扱い、位置を省略すると同じ中央の縮小領域を使う。

数値一点では、基準点が0〜1に入ることに加え、回転後の宣言した形が画面に収まることを検査する。はみ出した形を勝手に縮小・移動しない。名前や範囲による配置は、寸法を保ち、輪郭が画面の外へ出る場合がある。

数値範囲は横・縦それぞれの始まりを終わりより小さくし、全て0〜1に入れる。小数は小数点以下6桁まで、分数の分母は1〜1,000,000とする。二点間の座標にも同じ精度上限がある。

```ddl-ja
下（横0〜1、縦2/3〜1）に、赤い小さな円を埋める。
```

```ddl-en
fill small red circles at the bottom (horizontal 0 to 1, vertical 2/3 to 1).
```

`右下`・`下の方`など、名前だけでは受理しない位置の言葉を残したい場合も、直後の括弧にこの範囲を記せる。括弧の前の言葉は注記として保持し、**コンパイラが配置に使うのは括弧内の数値**である。自由な位置の言葉がすべて意味解析されるわけではない。既存の位置語を含む注記では、その位置語が示す領域に数値範囲を合わせる。

数値一点・数値範囲・名前付き位置を、ひとつの対象へ別々の位置 authority として重ねない。複数の図形を同じ文で扱う場合、数値指定の所有先を一つに決められなければ診断される。

### 3.9 二点間：並べる端、線の端

```ddl-ja
画面の横0.118、縦0.5から横0.882、縦0.5まで、半径0.03の青のロットリングの空の円を5個並べる。
```

```ddl-en
Line up 5 blue rotring empty circles radius 0.03 from horizontal 0.118, vertical 0.5 to horizontal 0.882, vertical 0.5.
```

並べる先頭と最後の痕の中心を、この二点に置く。中間は等間隔。右から左、下から上、斜めの二点も書ける。先頭は最初に書いた点であり、常に左になるわけではない。

二点は、1本の線・自由線の両端にも使える。

```ddl-ja
画面の横0.118、縦0.118から横0.882、縦0.882まで、灰の鉛筆の線を1本引く。
```

```ddl-en
draw one gray pencil line from horizontal 0.118, vertical 0.118 to horizontal 0.882, vertical 0.882.
```

二点は異なる点とし、全座標を0〜1へ入れる。数の精度は3.8と同じく、小数点以下6桁まで、分母1〜1,000,000とする。弧の端、1個だけの並べる、散らす、敷き詰める、埋めるにはこの構文を使わない。二点で線の長さと向きが決まるので、同じ線に長さ・全幅・角度を重ねない。二点で並べる向きも決まるので、外側の配置方向を重ねない。組やプラグイン呼び出しの外へ二点を付ける書き方も、一般の端点指定にはならない。

### 3.10 図形の向きと、並べる方向

`水平の線`は図形自身の向き。`線を縦に並べる`は複数の図形の配置方向である。日本語は図形の向きを head 前、並べる方向を head 後に置く。英語は形容詞と副詞で区別する。

```ddl-ja
中心に、横線を縦に三本並べる。
```

```ddl-en
arrange three horizontal lines vertically at center.
```

水平の線を3本、縦の列にする。`横`・`縦`は数値の座標軸にも使うため、数が続く軸の句と、図形の向きを分ける。

図形の向きには水平、垂直、斜め、右上がり、右下がり、回転がある。左上がり・左下がりも direct DDL で読むが、通常の歳時記表示や生成用語彙には出さない。`斜め`・`右上がり`などの定性的な角度は、有限の範囲から構図の種で選ぶ。特定の角度にしたい場合は数を書く。

```ddl-ja
画面の横0.5、縦0.5の位置に、一辺0.1の回転30度の赤い四角を1個置く。
```

```ddl-en
Place one red square side length 0.1 rotated 30 degrees at horizontal 0.5, vertical 0.5.
```

数値角度は画面上の時計回りで `0 <= 角度 < 360`。10進小数は小数点以下6桁まで。日本語は全角数字も使える。英語の1度は `1 degree`、他は `degrees`。分数・負の角度・360度以上は受理しない。数のない `回転`は種で角度を選ぶ語として残り、`回転30度`とは別である。同じ図形へ数値角度と `斜め`などを重ねると衝突する。点に向きは指定できない。

並べる方向の省略は、通常は横の左から右。名前／数値範囲が縦に長ければ縦になる。複数の痕を領域に並べるときは、領域中心を通る配置方向の直線が画面を切る区間に、等しいセルの中心として並ぶ。したがって、狭い範囲を指定しても列の端をその範囲の端へ固定する意味にはならない。列の先頭・末尾を固定したい場合は [3.9](#39-二点間並べる端線の端) を使う。

### 3.11 動作：置く・引く・並べる・散らす・敷き詰める・埋める

| 動作 | 使い分け |
|---|---|
| 置く / place | 形を一か所へ置く。複数なら、その場所の周囲の束になる |
| 引く / draw | 線・弧・自由線を引く。一般の「描画して」の言い換えではない |
| 並べる / line-up, line up, arrange | 一列へ配置。配置方向を指定できる |
| 散らす / scatter | 領域内へ分布させる。規則的な格子でも充填でもない |
| 敷き詰める / tile | 領域の縦横比に応じた格子へ配置する |
| 埋める / fill | 指定した領域の中へ痕を置き、その領域の輪郭で切り取る |

日本語の `描く`は現行 DDL の動作として採用しない。`塗る`も面の指定にはしない。閉じた面の塗りは `塗りの円`のように名詞で書く。

散らす・並べる・敷き詰めるは、明示した個数・個々の寸法を保つ。密集や重なりが生じても、数や寸法を減らす意味へ読み替えない。敷き詰めは規則を保ち、散らすのための薄れ・群れなどを自動で加えない。

### 3.12 埋める対象と、中に置く痕

```text
<領域を表す形>を<痕の名詞句>で埋める。
<名前付き領域>を<痕の名詞句>で埋める。
<痕の名詞句>で埋める。
fill <one target shape> with <marks>.
fill <marks> at <named area>.
```

対象を省略した埋めるは画面全体。`円を赤い点で埋める`では円が領域で、赤い点が痕である。領域の形へ、独立した塗り・輪郭を自動追加する意味ではない。

対象の形は、面積を持つ受理済みの閉じた輪郭ひとつにする。線・点を領域にはできない。複数の円を一つの対象として書く形、数値一点だけを埋める対象にする形は不成立。対象の形の位置は、数値一点でも領域でも指定できる。

痕の個数と寸法を明示すれば保つ。個数省略時は、対象面積を痕の代表寸法の2乗で割って切り上げるなど、共通の充填規則で決める。塗り・空・画材・さばきの違いを理由に個数は変えない。とても小さい点で広い面を埋めると、大きい資源需要になる。

塗りの色として背景を埋める文だけは、後述の背景色構文である。`背景を赤い点で埋める。`は痕による画面充填であり、背景色を赤にする意味ではない。

### 3.13 並列・組・順序列

**並列の対象**は、日本語の `と`、英語の `and`でつなぐ。各対象の修飾を、その対象へ付ける。

```ddl-ja
赤い円と青い四角を中心に並べて置く。
```

置き方を省略した並列の置くは、まとまりの中心を合わせる `overlap`。`重ねて置く`はそれを明示し、`並べて置く`は記述順に横へ並べたまとまりにする。各対象の個数は各対象に属し、後からひとつの総数として掛け直さない。

**組**は繰り返しの一単位になる名詞句である。

```text
<図形A>と<図形B>の組
a group of <shape A> and <shape B>
```

括弧内に命令を書いて組を定義しない。組の中の図形数と、外側の配置単位数を分ける。

**交互**は2項だけ。

```ddl-ja
鉛筆と太筆を交互にして、線を五本並べる。
```

色の列だけでなく、同じ属性カテゴリの道具なども交互にできる。異なる属性カテゴリを混ぜて「色と道具の交互」にしない。色や道具を二つ並べただけでは、交互を推測しない。

**順序付きの有限列**は、空でない列を記述順に使い、重複も保持する。

```ddl-ja
赤い小さな円・青い小さな線・灰の小さな弧の順に繰り返して、八つ並べる。
```

```ddl-en
Line up eight, repeating a small red circle, a small blue line, and a small gray arc in order.
```

円・線・弧・円・線・弧・円・線という8単位。列を使う動作は並べる・散らす・敷き詰める・埋める。列長は総個数を変えない。

```ddl-ja
赤い円と青い線の組を、灰の弧と交互に5つ並べる。
```

```ddl-en
Line up five, alternating a group of a red circle and a blue line with a gray arc.
```

これは「円＋線」の組が3つ、弧が2つ。外側は5単位、実際の primitive は円3・線3・弧2である。組やプラグインの内部構造も資源需要に含める。

### 3.14 色の移りと薄れ

色を循環させる `繰り返して`と、色列を一度だけ移す `段々に移して`を区別する。

```ddl-ja
画面の横0.1〜0.9、縦0.45〜0.55の範囲に、黄・橙・赤の順に段々に移して、小さな円を9個並べる。
```

```ddl-en
Line up 9 small circles in the range horizontal 0.1 to 0.9, vertical 0.45 to 0.55, shifting through yellow, orange, and red in order.
```

黄3個、橙3個、赤3個になる。色相を連続補間するグラデーションではなく、有限の色列へ痕を順に割り当てる。10個なら黄4・橙3・赤3となる。移せるのは並べる・敷き詰めるで、痕の数を色数以上にする。散らすや図形列の「段々に移して」は受けない。

薄れは次の5形だけを使う。

| 日本語 | 英語 | 対象 |
|---|---|---|
| 左から右へ薄れさせて | fading from left to right | 横成分を持つ2個以上の列 |
| 右から左へ薄れさせて | fading from right to left | 同上 |
| 上から下へ薄れさせて | fading from top to bottom | 縦成分を持つ2個以上の列 |
| 下から上へ薄れさせて | fading from bottom to top | 同上 |
| 中心から外へ薄れさせて | fading outward from the center | 2個以上の列または散布 |

日本語は配置の前に `…薄れさせて、`、英語は命令の後ろへ `, fading …`を置く。列の位置を変えず、指定した端から濃さが減る。縦の列に左右方向の薄れを指定するなど、列と直交する方向は不成立。敷き詰め、単独の形、方向付きの散らすへの薄れも不成立。ひとつの命令へ複数の薄れを重ねない。

さばきの `薄い`は各痕の基準の濃さであり、複数の痕を順に薄くするこの構文と併用できる。

### 3.15 関係：先に書いた対象へ結ぶ

関係は、次の **完全な固定句** を使う。単に `中に`や `つながる`という短い語が認識されたことと、参照先を持つ描画関係の成立は同じではない。

| 関係 | 日本語の固定句 | 英語の固定句 |
|---|---|---|
| 沿う | 前の線に沿って | along the previous line |
| 触れない | 前の形に触れない | not touching the previous shape |
| 触れる | 前の線に触れる | touching the previous line |
| 弧の両端で触れる | 前の弧に両端で触れる | touching the previous arc at both ends |
| 切る | 前の線を切る | cutting the previous line |
| 間に | 前の二つの間に | between the previous two |
| つながる | 前の形につながる | connected to the previous shape |
| 載る | 前の形に載る | resting on the previous shape |
| 中に | 前の形の中に | inside the previous shape |
| 重なる | 前の形に重なる | overlapping the previous shape |
| 横切る | 前の形を横切る | crossing the previous shape |
| 鏡写し | 前の形と鏡写し | mirrored with the previous shape |

前の対象は記述順で解決し、`間に`だけは前の二つを使う。任意の ID や前方参照を DDL に足さない。省略されて失われた対象の代わりに、さらに前の別対象へ参照を付け替えることもない。

日本語では関係句を図形の修飾として結ぶか、同じ命令内の後続句に置く。英語では命令の後ろに置く形が明瞭である。

```ddl-ja
左端に斜めの赤い弧を置く。右端に前の形と鏡写しの青い弧を置く。
```

```ddl-en
Place a diagonal red arc at left-edge. Place a blue arc at right-edge, mirrored with the previous shape.
```

関係が成立する形の組み合わせには制限がある。`中に`の相手には閉じた面積が必要で、内側へ収まらなければ不成立。`触れる`は線・弧などの両端を合わせる制約であり、任意の近接を言う語ではない。明示寸法・向き・数値位置を関係のために勝手に変更しない。不成立な関係は理由を残して関係だけを外し、形を元の配置で描く。

`切る`は視覚的な断絶を作る関係、`横切る`は相手の片方の縁から反対側まで越えて置く関係である。`重なる`は前の対象との関係、組の `重ねて置く`はその組の内部配置である。

### 3.16 接続の始点・終点・途中

`前の形につながる`は、現在の形の始点を、通常は前の形の終点へ合わせる。閉じた形の相手は円・楕円・四角・三角・多角形に限り、その近い輪郭点を使う。雲形・三日月は接続先にできない。対象が線・弧であれば、相手側のどこにつなぐかを明示できる。

```text
[前の]線の始点につながる
[前の]線の終点につながる
[前の]弧の始点につながる
[前の]弧の終点につながる
前の線の途中につながる
前の弧の途中につながる

connected to the start of the previous line
connected to the end of the previous arc
connected partway along the previous line
connected partway along the previous arc
```

現在の形の接続側は canonical な始点のまま。`終点を引く`などを足して、自分側の端を変える一般構文はない。無回転の通常線・通常弧では左が始点、右が終点であり、回転・鏡写し後も同じ端の identity を保つ。

`途中`は両端以外の一点であり、中央固定ではない。具体位置は演奏が決め、揺らいだ実際の中心線と外側の変形を反映する。通常 DDL に `target_path_position`などの Score フィールドは書かない。接線をそろえたり、寸法を自動補正したりする指定でもない。

自由線が現在側なら、端点でのつながる・触れるを受ける。触れる完全句が名指す相手は線・通常弧であり、自由線を相手にする触れる句は通常 DDL にない。自由線を相手にする通常 DDL は `前の形につながる`で終点へつなぐ。自由線の途中への接続、沿う・触れない・切る・間に・載る・中に・重なる・横切る・鏡写しは、関係を外して理由を残す。

### 3.17 道具・連続性・面・濃さ

道具は `鉛筆の`・`太筆の`などの名詞修飾。色・形と独立に指定する。道具を省略した場合の実行時解決はペンだが、にじみや質感から太筆を推測して明示扱いにすることはない。

連続性は実線・破線・点線・一点鎖線。これらは痕の線の連なり方であり、面の技法とは別である。英語の `solid`は連続性の実線、面の塗りは `flat`なので、両者を区別する。

おもては `空`・`塗り`・`刷き`・`刷毛目`・`粒`・`点描`・`平行線`・`交差線`・`アクアチント`。閉じた形では、明示した質感そのものが面を作り、平塗りを黙ってその下へ追加しない。下塗りを添えた場合だけ、画材の塗りを下へ敷く。

| 組み合わせ | 現行の扱い |
|---|---|
| 閉じた形＋空 | 塗らない |
| 閉じた形＋塗り、または面省略 | 塗る |
| 閉じた形＋名前付き質感 | その形の面に質感を置く |
| 線・通常の弧・自由線＋刷き | 道具の幅の3倍の帯を作る（太い・ごく太いは、既定の幅の3倍に太さの語が足す幅を足した帯）。帯の不透明度は道具の0.8倍 |
| 線・通常の弧・自由線＋粒 | その痕が受ける地の歯を強める |
| 線・通常の弧・自由線＋点描・平行線・交差線・アクアチント | コンパイラが受理して Score に保持するが、現行 renderer は開いた痕の面を描かない。閉じた形へ移す処理もない |
| 線・通常の弧・自由線＋刷毛目 | `unsupported_surface_brushmarks`。刷毛目だけを外す |
| 点＋明示したおもて | 未対応の面として診断し、その指定を外す |
| 三日月の弧＋塗り | 三日月の閉じた面として塗る |
| 三日月の弧＋その他の面 | 未対応の組み合わせとして診断 |

`点描`は面の技法、`点`は図形である。点を多数置くことと、円へ点描の面を付けることは別の指定。古い版の点描の意味で `点`を使わない。

さばきは `濃い`・`程よい`・`薄い`（`dense`・`temperate`・`faint`）。道具ごとの相対的な濃さを決める。程よいは道具本来の濃さで、さばき省略時と同じ演奏になる。複数の濃さを同じ痕へ付けると衝突する。

### 3.18 きめと下塗り

きめは、質感の一つ一つの痕の大きさと詰まり方を言う。

| 日本語 | 英語 | 指定 |
|---|---|---|
| 細かい | fine-grained | 質感の痕を小さくする |
| 粗い | coarse-grained | 質感の痕を大きくする |
| 密な | packed | 質感の痕を詰める |
| 疎な | sparse | 質感の痕を疎にする |
| 下塗り | underpainted | 質感の下へ画材の塗りを敷く |

```ddl-ja
中心に、赤の太筆の下塗りの密な交差線の薄い四角を1個置く。
```

閉じた形の名前付き質感7種（刷き・刷毛目・粒・点描・平行線・交差線・アクアチント）に使える。線・弧・自由線・点、空、塗り、面省略には付けない。未対応の組み合わせでは `unsupported_surface_fineness`・`unsupported_surface_underlayer`を記録し、その修飾だけを外す。

ひとつの痕へ、きめの4語から一つ、下塗りから一つを付けられる。`細かい密な点描`のようにきめを二つ重ねると、両方を衝突として外す。大きさと密度を別々に自由指定できる構文ではない。プラグインが出す痕へ外側からきめ・下塗りを上書きすることもできない。

`細かい`はきめ、`細かく`は揺らぎの振幅。`大きな`は図形の寸法、`大きく`は揺らぎの振幅である。

### 3.19 揺らぎとにじみ

| 次元 | 日本語 | 英語 |
|---|---|---|
| 振幅 | 細かく・大きく | narrowly・broadly |
| 波の間隔 | ゆるやかに・小刻みに | loosely・tightly |
| 揺れの質 | 揺れる・波打つ | swaying・undulating |
| 墨の広がり | にじみ | bleeding |

揺らぎも図形の前の修飾にするか、一意に定まる主語継続にする。`細かく揺れる線`、`ゆるやかに波打つ線`のように書く。`揺れる`は不規則な揺れ、`波打つ`は波状の揺れである。

振幅の `細かく`・`大きく`だけでは揺れを作らない。揺れる・波打つの語がない場合は `fluctuation_amplitude_without_quality`を出して、その振幅だけを外す。波の間隔だけを指定する場合の既存解決とは区別する。

にじみは揺れの質とは独立で、揺れと併用できる。にじみだけでは道筋に不規則な揺れを加えない。点への明示的な道筋の揺らぎは未対応である。道具そのものが持つ筆致や地への反応は、明示した揺らぎとは別に残る。

現行 DDL では `ゆっくり`・`震える`・`滲む`・`blurring`・`trembling`などの旧語を使わない。旧保存データの移行が、それらを現行語へ変換することと、新しく書く DDL の受理形は別である。

### 3.20 全幅・半幅と、弧の形

`全幅`・`半幅`は、回転前の幅を画面の全幅・半幅にする寸法指定。短辺の0.24を基準にする大小とは異なる。図形の比率を保ち、線・自由線では長さ、通常弧では弦長を指定する。回転後の見た目の水平幅を全幅へ戻す指定ではない。

半円・上弦・下弦・三日月は弧の head へ結ぶ。

```text
半円の弧 / semicircle arc
上弦の弧 / waxing arc
下弦の弧 / waning arc
三日月の弧 / crescent arc
```

半円は上側の180度の開いた弧、上弦は右側、下弦は左側の開いた弧。上弦・下弦は基準方向へ四分の一回転を加え、さらに数値角度を足せる。数値弦長・矢高を併記する半円形では、矢高を弦長の半分にする。

三日月は内外の曲線で閉じた面を持つ特定の形であり、一般の円弧とは異なる。縦長・横長・正形・任意の弦長矢高を三日月へ転用しない。幅と高さの明示も、その形が定める比率に合う必要がある。

### 3.21 地と背景色

地は支持体の名を、単独の文として書く。

```ddl-ja
和紙。
```

```ddl-en
washi.
```

紙・和紙・薄墨地・木炭地・カンバス・画用紙・メゾチントの7種。地はキャンバスそのものへ掛かり、図形の面ではない。`地: 和紙`・`Ground: washi`・`面: 点描`のような見出しを DDL に書かない。地はそれ自体で描画内容になる。

背景色は、次の固定形で書く。

```text
背景を<色>で埋める。
fill the background with <color>.
```

背景の色と地は併用できる。背景色だけは図形命令ではなく描画条件であり、省略診断の結果として背景しか残らなければ、描画対象が残った成功にはしない。背景を点や円で埋める場合は [3.12](#312-埋める対象と中に置く痕) の充填になる。

色は9つの抽象色で書き、作品の色カタログが実際の色へ解決する。DDL の色名に任意の hex 値や RGB 式を足さない。カタログ名・カタログモード・キャンバス形式（描く紙）・出力サイズ・各種 seed はホスト側の設定であり、可視 DDL の文法ではない。組んだ比は「画面比W:H。」で宣言する（[3.27](#327-画面比組んだ比を宣言する)）。

### 3.22 プラグインの呼び出し

プラグインは、コア語の組み合わせに名前を付けた data-only のマクロである。新しい primitive や、プラグイン専用の自由文法を持ち込むものではない。

```text
Namespace.Heading
Namespace.宣言済み別名
```

名前空間と見出しを半角のドットでつなぐ。正式名と、その定義が宣言した同じ名前空間内の別名だけを使う。たとえば `Nature.YoungLeaves`と`Nature.若葉`が同じ定義の正式名・別名である環境では、どちらも同じ定義を呼ぶ。ただし **Nature という固定のプラグインが全環境で使えることを意味しない**。

通常は登録一覧の正確な名前と、公開された引数の型・範囲を確かめ、呼び出しを一文にする。版・digest・lock・定義本体・展開結果を作者が DDL に書くことはない。関数呼び出し風の `Name(count=3)`を一般構文として作らない。

引数は、同じ句の受理済みの事実を、定義が宣言した型へ一意に結び付ける。たとえば整数を一つ受けることが明示された定義の fixture では、次の形を結合できる。

```text
Bind.Integerを八つ置く
Bind.Integer with 8
```

これは説明用定義 `Bind.Integer`が登録されている場合の例であり、通常環境へコピーして動くコア DDL ではない。引数名の文字から意味を推測せず、同じ型の引数が二つあって割り当てが二通りなら曖昧になる。別の文にある数値を拾って不足引数を補わない。

宣言した引数は原則必須。個数を受ける語の特別な宣言だけは、個数省略時に定義自身が決める。宣言されていない色・道具・角度・寸法・位置を外側へ付けても、出力全体を上書きする一般構文にはならない。結合できなかった明示指定を消して呼び出し成功扱いにはしない。

組や順序配置の member としてプラグインを使う場合、内部の個数・位置・変形を保ち、外側の一単位として配置する。外側の個数と、内部の痕の個数を混同しない。

| 診断 | 意味 |
|---|---|
| plugin_not_installed | 名前の定義がない |
| plugin_disabled | 定義は導入済みだが無効 |
| plugin_name_mismatch | 正式名・別名・名前空間・大文字小文字が登録と合わない |
| plugin_version_mismatch | 同名だが固定した定義の中身と一致しない |
| plugin_count_out_of_range | 個数がその語の受ける範囲外 |

未解決のプラグイン文は理由を示して、その文だけを省略する。LLM が別の形へ黙って置換しない。保存済み作品は使用した定義を保持する。別環境へ可視 DDL だけをコピーすると定義は運べないため、必要なときはアプリケーションの DDL 書き出しを使う。書き出しが持つ定義は新しい作品に使え、環境へのインストールとは別である。定義そのものを書く場合は [PLUGIN.md](../../PLUGIN.md) を参照する。

### 3.23 未指定、衝突、局所回復を読む

コンパイラが語を認識したこと、意味の所有先を決めたこと、描画できたことは別の段階である。語彙表に載っていても、対象がなければ属性は結べない。数値や関係が妥当でも、資源制限によって配置が省略されることがある。

| 典型例 | 読み方・直し方 |
|---|---|
| 知らない形容詞や動詞 | 歳時記の受理形と有限の core 修飾へ書き分ける |
| 色二つを単独図形へ無順序で指定 | 色を一つにするか、交互・順序列を明示する |
| 寸法を二つ以上指定 | 小さい候補へ回復した診断を確認し、意図する寸法一つへ整理する |
| 数値位置と名前付き位置を併記 | 一つの位置 authority を選ぶ |
| 独立した二つの線の後で `線は…` | 導入文へ属性を戻し、一意性を確保する |
| きめを空の面へ指定 | 対応する質感を指定するか、きめを外す |
| 刷毛目を線へ指定 | 閉じた面へ使うか、別の受理済みの面を選ぶ |
| 数値一点を `埋める`領域にする | 面積を持つ領域または形を指定する |
| 関係の相手が存在しない・不適合 | 文順・相手の形・固定句を確認する |

回復可能な問題は、属性、関係、命令、組、マクロなど、成立を保てる最小の単位で診断し、残る描画を続ける。関係だけを外す場合と、外側の配置全体を外す場合を混同しない。全ての描画対象が省略された場合、または source・lock・所有関係などの整合性が壊れている場合は停止する。

AI が DDL を書くときも、この診断を隠して成功としない。対象・明示個数・寸法・色・画材・関係を落として形式だけを通す修正は、作者の指定を保持した修正ではない。

### 3.24 書き終える前の確認

1. 描く対象ごとに、図形の head と受理済みの動作があるか。
2. 色・道具・面・揺らぎ・数・位置が、どの対象に掛かるか一つに決まるか。
3. 図形の向きと、並べる方向を別の場所へ書いたか。
4. 数値一点・範囲・二点間を、意図に合う構文で使ったか。
5. 個数は一つの完結した表現か。組・列の総数を掛け直していないか。
6. 関係は完全な固定句か。必要な先行対象があるか。
7. 面・きめ・下塗り・揺らぎは、その形へ適用できるか。
8. プラグイン名と引数は、その環境の宣言に存在するか。
9. 説明文・Score のフィールド・設定・metadata を DDL へ混ぜていないか。

### 3.26 CLI から DDL を入力する

本文だけを UTF-8 の `example.ddl` に保存し、既存の CLI 接続設定を使って入力できる。

```sh
inku-cli paint --file example.ddl --input-mode ddl \
  --stage1-model chatgpt:gpt-6-luna --instruction-lang ja \
  --no-save-artifacts -o ./out
```

英語の本文なら `--instruction-lang en` を使う。`--input-mode ddl`は自然記述の解釈を飛ばし、可視DDLを共有コンパイラへ渡す。完成して受理されたDDLの処理はLLMを必要としないため、`--stage1-model`でモデルを明示したこと自体は、そのモデルを実際に呼び出した証拠にはならない。未受理部分の補完案など、LLMが必要な経路に入った場合と区別する。

`--no-save-artifacts`はサーバー側の派生ファイル保存を抑える指定。`-o ./out`はCLIの出力先である。ライブラリへの履歴保存は `--save-history` を付けた場合だけ行う。接続・認証、出力と保存の詳細は [CLI リファレンス](cli-reference.md) を参照する。

### 3.27 画面比：組んだ比を宣言する

DDL は、組んだときの紙の比を、独立した一文で宣言する（DDL 26）。

```ddl-ja
画面比16:9。
画面の横0.5、縦0.5の位置に、半径0.1の赤い円を1個置く。
```

```ddl-en
Aspect ratio 16:9.
place one red circle radius 0.1 at horizontal 0.5, vertical 0.5.
```

- 数は横:縦の順の整数で、1〜10000。日本語は全角の数字と `：` も受ける。`画面比32:18。` は `16:9` と同じ宣言になる。小数、0、ほかの語を含む文は宣言にならない。
- 宣言は命令を作らず、文の数え方にも入らない。宣言を足しても消しても、ほかの文の読みは変わらない。同じ比の紙なら描く画も変わらない。
- 宣言は最初の一文だけを読む。二つ目からは読めない文として除き、診断に残す。
- アプリは、新しい DDL の先頭に描く紙の比を書き入れる（記述から描いた DDL と、新しく書いた DDL）。作者が書いた宣言は残し、編集や描き直しでは文を足さない。
- 宣言は紙を縛らない。宣言と違う比の紙で描くとき、アプリは「はめ込んで描く」か「この紙に合わせて描く」かを尋ねる。はめ込むと、構図はそのままの比で紙の中央の枠に入り、余白は地と背景になる。枠からはみ出す痕は紙の端まで描く。
- 紙の比の名（`square` など）は書かない。比は数で書く。黄金は `809:500`、A4 と B4 は `500:707` である。

## 4. 歳時記：全語彙と受理する別形

日本語を正本とする。語の綴りは `inku.saijiki.v2`（`core/crates/inku-ddl/assets/saijiki-v2.json`）に合わせる。本節は15カテゴリの全102行と、別表の「あいだ」11行を扱う。102行には、表示される98行、表示しないが直接DDLで使える3行、受理しない廃止行1行が含まれる。「あいだ」は画面では16番目のカテゴリとして並ぶ。

### 読み方と書き方

表の「日本語」「英語」は同じ語の正規表記である。指示書の言語で一方を使う。英語の空白やハイフンも語の一部で、`free line`、`oil paint`、`fine-brush`、`left-edge`のように書く。表の例は語を使う短い形であり、作品の見え方を固定する見本ではない。位置や大きさを省略した部分は、後述の解決規則と演奏によって決まる。

形を名詞の中心にし、その前に属性を付け、動作へ結ぶ。例えば `赤の鉛筆の薄い点描の円を置く。` と書く。地は図形の属性にせず、`和紙。` のように独立した文にする。`地: 和紙`、`面: 点描`という見出し形式は使わない。面なら `点描の円を置く。` と書く。

一つの痕に対して同じ属性の複数語を併記すると衝突になりうる。「細かい」と「密な」は両方とも「きめ」の同じ欄であり、二つを一緒に指定しない。「下塗り」は別の欄なので `下塗りの密な点描の円` のように併用できる。成立しない属性や関係は診断付きで省略され、独立して描ける残りが続く。語の認識、Scoreへの受理、実際にその形で見える効果は区別する。

`default=true`のペン・実線・空・黒は資料上の注記である。`（既定）`や`(default)`はDDL語の一部ではない。書かれていない属性は読み取り時には未指定のままであり、語彙表の注記を本文へ補わない。現行のScore解決では、省略した道具はペン、線種は実線、閉じた形の面は塗りになる。省略色は実際の背景または地との明度差で黒・白から選ぶ。したがって「空が既定と記載されているから、面を省くと空になる」とは読まない。

| `gamen` | がめん | aspect | 0 | 画面比の宣言（3.27）を表示する。歳時記の語ではない |

### 4.1. かたち — forms

図形の名詞である。「閉じた形」は、以下の円・楕円・三角・四角・雲形・多角形を指す。「開いた痕」は線・弧・自由線を指す。点と、弧の三日月形は個別の制限を持つ。

| 日本語 | 英語 | 意味・受理範囲 | 短い書き方 |
|---|---|---|---|
| 円 | `circle` | 正円。閉じた形。半径または直径を指定できる。 | `赤い円を置く。` / `Place a red circle.` |
| 楕円 | `ellipse` | 一方向へ伸びた円。閉じた形。縦長・横長、幅と高さを指定できる。 | `横長の楕円を置く。` / `Place a wide ellipse.` |
| 三角 | `triangle` | 三頂点の閉じた形。縦長・横長、幅と高さを指定できる。正三角形は別の形修飾構文。 | `上に三角を置く。` / `Place a triangle at top.` |
| 四角 | `square` | 矩形の閉じた形。縦長・横長を受ける。英語の正規語がsquareでも、長方形を別primitiveにはしない。 | `横長の四角を置く。` / `Place a wide square.` |
| 線 | `line` | 始点から終点へ直線を引く。引く・置く、配列・散布・充填に使える。 | `水平の線を引く。` / `Draw a horizontal line.` |
| 弧 | `arc` | 円弧。通常は開いた痕。半円・上弦・下弦・三日月はこの名詞を修飾する。 | `半円の弧を引く。` / `Draw a semicircle arc.` |
| 自由線 | `free line` | 両端の間の道筋を、演奏ごとに直線・円弧・自由な曲がりから組む。関係はつながる・触れるだけを受ける。 | `右上がりの自由線を引く。` / `Draw a rising free line.` |
| 点 | `point` | 円とは別の、丸く塗られた小さな痕。面・図形自体の角度・揺れの指定を受けない。にじみは使える。 | `緑の点を置く。` / `Place a green point.` |
| 雲形 | `cloudform` | 演奏ごとに輪郭が決まる不規則な閉じた形。縦長・横長を受ける。 | `横長の雲形を置く。` / `Place a wide cloudform.` |
| 多角形 | `polygon` | **非表示の受理語**。`prompt=false`・`display=false`・`marker=true`。直接DDLでは有効。現行は5〜8辺、辺数省略は5。 | `多角形を置く。` / `Place a polygon.` |

直接DDLは、三角形→三角、四角形・長方形→四角、`rectangle`→`square`、`lines`→`line`も読む。これらはparserだけの別表記で、正規語の追加ではない。英語の登録形名詞は規則的な複数形（`circles`、`free lines`など）も読むが、複数形そのものから個数を推測しない。

正三角形・正方形・正四角形、五角形〜八角形（`equilateral triangle`、`regular square`、`pentagon`〜`octagon`）は、形のidentityに正則性や辺数を付ける有限文法である。歳時記の追加行ではない。正形と縦長・横長は併用しない。

### 4.2. かたむき — angles

図形自体の向きである。点には方向がないため使えない。`水平の線を縦に並べる。` のように、各痕の向きと列の向きを分けて書ける。下表の角度は画面のy軸が下向きの、時計回りの角度である。

| 日本語 | 英語 | 意味・受理範囲 | 短い書き方 |
|---|---|---|---|
| 水平 | `horizontal` | 0度。列の向きにも使える。 | `水平の線を引く。` / `Draw a horizontal line.` |
| 垂直 | `vertical` | 90度。列の向きにも使える。縦長の形もさらに90度回す。 | `垂直の線を引く。` / `Draw a vertical line.` |
| 斜め | `diagonal` | 45・135・225・315度から構図seedで選ぶ。列では二つの斜め方向から選ぶ。 | `斜めの四角を置く。` / `Place a diagonal square.` |
| 右上がり | `rising` | 左下から右上へ。整数−37〜−23度から選ぶ。直接DDLの列方向にも使える。 | `右上がりの線を引く。` / `Draw a rising line.` |
| 右下がり | `falling` | 左上から右下へ。整数23〜37度から選ぶ。直接DDLの列方向にも使える。 | `右下がりの線を引く。` / `Draw a falling line.` |
| 左上がり | `left-rising` | **非表示の受理語**。右下から左上へ向く203〜217度。右上がりと同一identityにしない。 | `左上がりの線を引く。` / `Draw a left-rising line.` |
| 左下がり | `left-falling` | **非表示の受理語**。右上から左下へ向く143〜157度。右下がりと同一identityにしない。 | `左下がりの線を引く。` / `Draw a left-falling line.` |
| 回転 | `rotated` | 各45度境界から5度を超えて離れた整数角度を選ぶ。列方向の語にはしない。 | `回転の四角を置く。` / `Place a rotated square.` |

左上がり・左下がりは、いずれも`prompt=false`・`display=false`・`marker=true`で、直接DDLとMacro参照は受ける。水平の`横`、垂直の`縦`はparser別表記である。英語は`horizontally`・`vertically`・`diagonally`も同じ行の文法形として読む。任意の副詞を追加したり、`rotated`に自由な同義語を与えたりはしない。

`回転30度の四角` / `a square rotated 30 degrees`の数値角度は別の有限構文である。数のない回転とは区別し、一つの痕へ角度語と数値角度を重ねない。

| ロットリング | `rotring` | 均一な線幅と角端を持つ硬い製図線。 | `ロットリングの線を引く。` / `Draw a rotring line.` |
| クレヨン | `crayon` | 蝋の擦れに短い途切れと粒状の欠けが残る。 | `クレヨンの線を引く。` / `Draw a crayon line.` |
| チョーク | `chalk` | 粉状のかすれ、細かな隙間、軽いぼけを持つ。 | `チョークの線を引く。` / `Draw a chalk line.` |

| 油彩 | `oil paint` | 絵具が残る筆跡に刷毛筋と重なりが現れる。 | `油彩の線を引く。` / `Draw an oil paint line.` |

| ドライポイント | `drypoint` | まくれによる柔らかな毛羽立ち、にじみ、かすれを持つ。 | `ドライポイントの線を引く。` / `Draw a drypoint line.` |

### 4.4. つらなり — continuity

輪郭や線の連なり方である。全primitiveで語として受理するが、点は短い線の集まりではなく一つの点なので、線種を付けても点の列や個数にはならない。面の点描とも別の属性である。

| 日本語 | 英語 | 意味 | 短い書き方 |
|---|---|---|---|
| 実線 | `solid` | 切れ目のない線。資料上の既定注記がある。 | `実線の線を引く。` / `Draw a solid line.` |
| 破線 | `dashed` | 短い線分を間隔を空けて並べる。 | `破線の線を引く。` / `Draw a dashed line.` |
| 点線 | `dotted` | 点の連なりで輪郭を表す。 | `点線の円を置く。` / `Place a dotted circle.` |
| 一点鎖線 | `dash-dot` | 長い線分と点を交互に置く。 | `一点鎖線の線を引く。` / `Draw a dash-dot line.` |

`solid`はつらなりの語である。面の塗りの英語は`flat`であり、内部のScore値`solid`を本文の面の語にしない。

### 4.5. おもて — surfaces

閉じた形の面や、痕がどう在るかを言う状態の名詞である。濃さは「さばき」、質感の単位の大きさと詰まり方は「きめ」、支持体は「じ」で分けて書く。

| 日本語 | 英語 | 意味 | 短い書き方 |
|---|---|---|---|
| 空 | `empty` | 面に何も置かず輪郭を残す。資料上の既定注記がある。 | `空の四角を置く。` / `Place an empty square.` |
| 塗り | `flat` | 面を一様に塗る。 | `塗りの四角を置く。` / `Place a flat square.` |
| 刷き | `sweep` | 面を少し角度を変えて二度掃き、各掃きの帯を一枚の膜にする。開いた痕では幅広い帯になる。 | `刷きの四角を置く。` / `Place a sweep square.` |
| 刷毛目 | `brushmarks` | 帯を一本ずつ重ね、重なった所が濃い筋になる。閉じた形の面だけに使う。 | `刷毛目の四角を置く。` / `Place a brushmarks square.` |
| 粒 | `grain` | 細かな粒と擦れた粗さを作る。開いた痕では支持体の歯を強める。 | `粒の四角を置く。` / `Place a grain square.` |
| 点描 | `stipple` | 面に点を撒いて濃淡を作る。形の点とは別の語。 | `点描の円を置く。` / `Place a stipple circle.` |
| 平行線 | `hatch` | 平行な線で面を埋める。線の名詞を複数置く指定とは別。 | `平行線の四角を置く。` / `Place a hatch square.` |
| 交差線 | `crosshatch` | 平行線にもう一組を交差させる。 | `交差線の四角を置く。` / `Place a crosshatch square.` |
| アクアチント | `aquatint` | 粒の濃さを段に分ける。通常は三段。 | `アクアチントの四角を置く。` / `Place an aquatint square.` |

| 対象 | 受理と演奏の制限 |
|---|---|
| 円・楕円・三角・四角・多角形・雲形 | 9語を受理し、面を演奏する。名前付き7質感は、それだけなら下に平塗りを重ねない。 |
| 線・通常の弧・自由線 | 刷き・粒は痕へ効果を持つ。空・塗り・点描・平行線・交差線・アクアチントもcompilerでは受理してScoreに残るが、開いた痕に閉じた面の質感は描かない。別の閉じた形へ転送しない。刷毛目は診断付きでその語だけを外す。 |
| 点の痕 | 面の9語を受理しない。点自体は丸い塗られた痕として残る。 |
| 三日月の弧 | 面の明示指定は塗りだけを受理する。空・7質感は受理しない。 |

刷きは自らの「薄さ」を持たない。薄くしたいときは `薄い刷き` と書く。開いた痕の刷きは道具の幅の3倍の帯、道具の不透明度の0.8倍になる。太い・ごく太いの帯は、既定の幅の3倍に、太さの語が丸筆に足す幅だけを足した幅になる（例: 太筆のごく太いは、短辺1000当たり150でなく66）。面の刷きは一掃き0.6倍の膜を二度、刷毛目は一本ずつ0.5倍で重ねる。道具とさばきも見え方に作用する。

`塗りの弧`は、両端のTouchingで閉じる弧の内側を塗る意図にも使える。単独の通常弧や線に塗りを書くだけで、別の閉じた形を作る意味にはならない。

### 4.6. さばき — handling

道具に対する相対的な濃さであり、点や線の数を増減する語ではない。線・弧・自由線・閉じた形の面・点で受理する。同じ痕に複数のさばき語を重ねない。

| 日本語 | 英語 | 意味 | 短い書き方 |
|---|---|---|---|
| 濃い | `dense` | 道具の本来の濃さより濃く置く。 | `鉛筆の濃い点描の四角を置く。` / `Place a dense stipple pencil square.` |
| 程よい | `temperate` | 道具の本来の濃さで置く。省略した痕と同じ濃さだが、明示した語として残る。 | `鉛筆の程よい点描の四角を置く。` / `Place a temperate stipple pencil square.` |
| 薄い | `faint` | 道具の本来の濃さより淡く置く。 | `鉛筆の薄い点描の四角を置く。` / `Place a faint stipple pencil square.` |

### 4.7. きめ — fineness

閉じた6形の名前付き7質感（刷き・刷毛目・粒・点描・平行線・交差線・アクアチント）だけに使う。空・塗り・面の省略、線・弧・自由線・点、Macroが出す痕には付けない。不成立ならその語だけを診断付きで外す。一つの痕で下表から一語を選び、「細かい」と「密な」も併記しない。

| 日本語 | 英語 | 意味 | 短い書き方 |
|---|---|---|---|
| 細かい | `fine-grained` | 点や線の一つを小さくし、その分数を増やして覆う広さを保つ。 | `細かい点描の円を置く。` / `Place a fine-grained stipple circle.` |
| 粗い | `coarse-grained` | 点や線の一つを大きくし、その分数を減らして覆う広さを保つ。 | `粗い粒の楕円を置く。` / `Place a coarse-grained grain ellipse.` |
| 密な | `packed` | 同じ大きさの点や線の詰まり方を密にする。 | `密な平行線の四角を置く。` / `Place a packed hatch square.` |
| 疎な | `sparse` | 同じ大きさの点や線の詰まり方を疎にする。 | `疎なアクアチントの雲形を置く。` / `Place a sparse aquatint cloudform.` |

「細かい」は質感、「細かく」は揺れの振幅である。「密な」は質感の詰まり方、「濃い」は道具に対する濃さである。内部の値では細かい・粗いが`scale`を0.05・0.90、密な・疎なが`density`を0.85・0.05にするが、その値をDDL本文へ書く必要はない。

### 4.8. したじ — underlayer

適用範囲は「きめ」と同じで、閉じた6形の名前付き7質感だけである。さばき一語・きめ一語と併用できる。

| 日本語 | 英語 | 意味 | 短い書き方 |
|---|---|---|---|

### 4.11. ゆらぎ — movements

痕の不均一さを指定する。振幅・間隔・揺れの質は各一語、にじみは別の一語として併用できる。線・弧・自由線と閉じた6形は揺れを受ける。点は揺れを受けず、にじみだけを受ける。

| ゆるやかに | `loosely` | 波の間隔を広げる。描画の時間や速度ではない。 | `ゆるやかに波打つ線を引く。` / `Draw a loosely undulating line.` |
| 小刻みに | `tightly` | 波の間隔を詰める。描画の時間や速度ではない。 | `小刻みに揺れる線を引く。` / `Draw a tightly swaying line.` |
| 揺れる | `swaying` | 連続する不規則な揺れ。 | `揺れる線を引く。` / `Draw a swaying line.` |
| 波打つ | `undulating` | 波形の規則的なうねり。 | `波打つ線を引く。` / `Draw an undulating line.` |
| にじみ | `bleeding` | 墨の縁に不均一な広がりを加える。揺れとは独立し、単独では揺れを加えない。 | `にじみの円を置く。` / `Place a bleeding circle.` |

振幅の細かく・大きくだけを書いたときは、`fluctuation_amplitude_without_quality`としてその語だけを省略する。ゆるやかに・小刻みにはこの制限がなく、揺れの質を省いたときは不規則な揺れを使う。揺れの他の省略成分は中程度で解決するが、ゆらぎをまったく書かない痕へ明示ゆらぎを補う規則ではない。

英語の`sways`・`undulates`は同じ行の許された文法形である。`fine`や`large`を振幅の別名としては読まない。`large`は図形の大小の修飾語である。

### 4.12. ばしょ — places

位置は固定点だけでなく領域を表す。以下の座標は画面の左上を(0,0)、右下を(1,1)とした範囲である。置く・引くは範囲を中心のまわりで2/3へ縮めた中から基準点を選び、並べる・散らす・敷き詰めるは範囲を使って配置する。始点・終点・途中は画面内の独立した配置領域にはしない。

| 日本語 | 英語 | 意味・受理範囲 | 短い書き方 |
|---|---|---|---|
| 上 | `top` | 上の1/3の帯 `[0,0,1,1/3]`。 | `上に円を置く。` / `Place a circle at top.` |
| 下 | `bottom` | 下の1/3の帯 `[0,2/3,1,1]`。 | `下に円を置く。` / `Place a circle at bottom.` |
| 中心 | `center` | 中央の升目 `[1/3,1/3,2/3,2/3]`。固定の一点ではない。 | `中心に円を置く。` / `Place a circle at center.` |
| 左端 | `left-edge` | 左の1/10の帯 `[0,0,1/10,1]`。 | `左端に円を置く。` / `Place a circle at left-edge.` |
| 右端 | `right-edge` | 右の1/10の帯 `[9/10,0,1,1]`。 | `右端に円を置く。` / `Place a circle at right-edge.` |
| 上端 | `top-edge` | 上の1/10の帯 `[0,0,1,1/10]`。 | `上端に線を引く。` / `Draw a line at top-edge.` |
| 下端 | `bottom-edge` | 下の1/10の帯 `[0,9/10,1,1]`。 | `下端に線を引く。` / `Draw a line at bottom-edge.` |
| 始点 | `start` | 先行する線・弧の始点を接続先にする。単独の`始点に円を置く`には使わない。 | `前の線の始点につながる弧を引く。` / `Draw an arc connected to the start of the previous line.` |
| 終点 | `end` | 先行する線・弧の終点を接続先にする。単独の画面位置ではない。 | `前の弧の終点につながる線を引く。` / `Draw a line connected to the end of the previous arc.` |
| 途中 | `partway` | 先行する線・弧の両端以外を接続先にし、場所は演奏で選ぶ。自由線の途中は対象にしない。 | `前の線の途中につながる弧を引く。` / `Draw an arc connected partway along the previous line.` |
| 隅 | `corner` | 幅・高さが各1/5の四隅の領域から一つを構図seedで選ぶ。 | `隅に円を置く。` / `Place a circle in a corner.` |

英語の`left edge`・`right edge`・`top edge`・`bottom edge`も同じ行を指すparser別表記である。名前の位置と数値の位置・範囲・両端を同じ痕に併記すると衝突する。位置を省くと、置く・引くは中心と同じ範囲、並べる・散らす・敷き詰める・埋めるは全画面を使う。

表の始点・終点・途中の例には、直前の文で描いた相手が必要である。始点・途中の例の前には `赤い線を引く。` / `Draw a red line.`、終点の例の前には `赤い弧を引く。` / `Draw a red arc.` を置く。これらの関係句だけを空の指示書へ貼ると、先行対象なしの診断になる。

### 4.13. うごき — motions

静止画の中で痕をどう配置するかを言う。動かすアニメーションではない。引くを除く公開5語は全10primitiveを受理し、引くは線・弧・自由線だけを受理する。

| 日本語 | 英語 | 意味・受理範囲 | 短い書き方 |
|---|---|---|---|
| 置く | `place` | 一か所へ置く。個数を省くと1。 | `中心に円を置く。` / `Place a circle at center.` |
| 並べる | `line-up` | 図形や組を一列に並べる。列の向きは各図形の向きと別。個数省略は8。 | `円を五つ並べる。` / `Line up five circles.` |
| 引く | `draw` | 線・弧・自由線を置く。閉じた形や点を描く汎用動詞にはしない。 | `線を三本引く。` / `Draw three lines.` |
| 描く | なし | **廃止行**。`prompt=false`・`display=false`・`marker=false`で、現在のparserは受理しない。英語のdrawはこの行の訳ではなく引くの語。 | 現行DDLでは使わず、`円を置く。` / `Place a circle.`と書く。 |
| 散らす | `scatter` | 不規則に散布する。埋めるや規則的な敷き詰めに読み替えない。個数省略は8。 | `点を五つ散らす。` / `Scatter five points.` |
| 埋める | `fill` | 対象の領域を密な不規則配置で満たし、境界で切り抜く。 | `三つの赤い円と四つの青い点で埋める。` / `Fill with three red circles and four blue points.` |
| 敷き詰める | `tile` | 規則的・反復的な格子に配置する。個数省略は8。 | `四角を九つ敷き詰める。` / `Tile nine squares.` |

並べるの`line up`・`arrange`はparser別表記である。英語の閉包markerは互換上`arrange`を使うが、歳時記の正規語は`line-up`である。

埋めるの対象は、全画面、名前の領域、文中で指定した単一の閉じたprimitiveにできる。対象の形は独立した追加描画ではない。明示した個数は保ち、個数省略は対象面積と痕の寸法から決める。面積を持たない対象や受理範囲外の幾何は診断になる。大きな個数には資源上限が適用されるため、短い例は配送や無制限の実行を保証するものではない。

### 4.14. じゅん — order

同じ属性の有限列、図形の有限列、組の有限列を、並べる・散らす・敷き詰める・埋めるへ接続する。個数は配置単位の総数であり、列の長さではない。組の内部の図形数を外側の個数へ掛けない。

| 日本語 | 英語 | 意味・制限 | 短い書き方 |
|---|---|---|---|
| 交互に | `alternating` | ちょうど2項を交互に巡る。3項以上を交互とはしない。 | `赤と灰を交互にして、円を五つ並べる。` / `Line up five circles, alternating red and gray.` |
| 順に | `in order` | 空でない有限列を記述順に巡る。同じ項の重複も保つ。 | `赤・赤・青の順に繰り返して、円を八つ並べる。` / `Line up eight circles, repeating red, red, and blue in order.` |

「繰り返して」や「組」は文法で、歳時記に追加された語ではない。順にの色列は `黄・橙・赤の順に段々に移して、円を九つ並べる。` のように一度だけ移す文法にも使う。この推移は並べる・敷き詰めるだけで、形・組・道具の列を連続変形する意味にはしない。

### 4.15. わりあい — proportions

形の縦横、画面に対する大きさ、弧の形を指定する。これらは別の次元であり、全幅・半幅を「水平に置く」の同義にはしない。

| 日本語 | 英語 | 意味・受理範囲 | 短い書き方 |
|---|---|---|---|
| 縦長 | `tall` | 三角・四角・楕円・雲形の縦を長くする。通常比は2:1。正形とは併用しない。 | `縦長の四角を置く。` / `Place a tall square.` |
| 横長 | `wide` | 同じ4形の横を長くする。通常比は2:1。正形とは併用しない。 | `横長の楕円を置く。` / `Place a wide ellipse.` |
| 全幅 | `full-width` | 痕の基準寸法を画面の横幅にする。自由線なら弦長。回転や名前位置によるはみ出しまで防ぐ語ではない。 | `全幅の線を引く。` / `Draw a full-width line.` |
| 半幅 | `half-width` | 痕の基準寸法を画面の横幅の半分にする。 | `半幅の線を引く。` / `Draw a half-width line.` |
| 半円 | `semicircle` | 弧の弦長に対する矢高を半分にし、180度の開弧にする。弧以外には使わない。 | `半円の弧を引く。` / `Draw a semicircle arc.` |
| 上弦 | `waxing` | 右へ膨らむ180度の開弧。指定角度に90度を加える。 | `上弦の弧を引く。` / `Draw a waxing arc.` |
| 下弦 | `waning` | 左へ膨らむ180度の開弧。指定角度に270度を加える。 | `下弦の弧を引く。` / `Draw a waning arc.` |
| 三日月 | `crescent` | 弧を細い月形の閉じた特殊形にする。塗り以外の面、きめ・下塗りを受けない。 | `三日月の弧を引く。` / `Draw a crescent arc.` |

縦長の`縦に長い`・`細長い`、横長の`横に長い`はparser別表記である。数値の幅・高さも書いた場合はその数を保ち、縦長なら高さが幅より大きいこと、横長なら幅が高さより大きいことを確認する。

全幅・半幅は通常の全10primitiveに使える。数値寸法・大小の語・全幅や半幅を重ねた大きさの候補は、診断を残して小さい候補を採る。二つの数値端点で定義した一本の線・自由線は端点が長さを決めるため、全幅・半幅と併用しない。半円・上弦・下弦・三日月は独立した形名詞ではなく、必ず弧に付ける。

### 4.16. あいだ — relations

短い語は関係の名前であり、それだけでは先行対象を指定しない。実際の関係には、下表の「前の…」を含む完全な句を使う。現在の痕から直前の痕を参照し、間にだけは直前の二つを参照する。参照先が省略されても、別の残存図形へ付け替えない。一つの命令に関係は最大一つである。

| 日本語 | 英語の短い語 | 完全な日本語句 | 完全な英語句 | 意味・受理範囲 |
|---|---|---|---|---|
| 沿う | `along` | `前の線に沿って` | `along the previous line` | 現在も先行も線。方向未指定なら平行に合わせる。寸法や明示方向は保つ。 |
| 触れない | `not touching` | `前の形に触れない` | `not touching the previous shape` | 先行する痕と間隔を残す。自由線がいずれかにある場合は使えない。 |
| 触れる | `touching` | `前の線に触れる` / `前の弧に両端で触れる` | `touching the previous line` / `touching the previous arc at both ends` | 両端を一致させる。現在は線・通常弧・自由線。先行は完全句が名指す線・通常弧であり、自由線を相手にする完全句はない。 |
| 切る | `cutting` | `前の線を切る` | `cutting the previous line` | 現在も先行も線。交差させる。寸法や明示方向は保つ。 |
| 間に | `between` | `前の二つの間に` | `between the previous two` | 直前二つの外接矩形の中心の間に置く。自由線が関係する場合は使えない。 |
| つながる | `connected` | `前の形につながる` | `connected to the previous shape` | 現在の始点を先行の終点へ合わせる。現在は線・通常弧・自由線・点。先行はこれらか、円・楕円・三角・四角・多角形の輪郭。雲形・三日月を先行にしない。 |
| 載る | `resting on` | `前の形に載る` | `resting on the previous shape` | 現在の下端を先行の上端へ合わせる。外接矩形を使う。点を先行対象にできず、自由線はどちら側にも使えない。 |
| 中に | `inside` | `前の形の中に` | `inside the previous shape` | 先行する閉じた6形（円・楕円・三角・四角・多角形・雲形）の内側へ現在を収める。開いた形・点・三日月を容器にはせず、入らなければ不成立。自由線は使えない。 |
| 重なる | `overlaps` | `前の形に重なる` | `overlapping the previous shape` | 外接矩形の一部を重ねる。点を先行対象にできず、自由線はどちら側にも使えない。英語の短い語と完全句の綴りの違いを保つ。 |
| 横切る | `crossing` | `前の形を横切る` | `crossing the previous shape` | 先行の片側から反対側を越える。現在が短すぎれば不成立。自由線は使えない。 |
| 鏡写し | `mirrored` | `前の形と鏡写し` | `mirrored with the previous shape` | 二つの形または組の間の軸に対して位置と向きを鏡映する。色や道具をコピーしない。不適合な形どうしや自由線では関係を外す。 |

完全な短い例は `赤い線を引く。前の線に沿って青い線を引く。` / `Draw a red line. Draw a blue line along the previous line.` となる。`along`だけを書いて近くの線を自動選択させる意味にはしない。

つながるでは、対象の線・弧に対して次の有限句も使える。

| 選択 | 日本語 | 英語 |
|---|---|---|
| 始点への接続 | `[前の]線/弧の始点につながる` | `connected to the start of the previous line/arc` |
| 終点への接続 | `[前の]線/弧の終点につながる` | `connected to the end of the previous line/arc` |
| 途中への接続 | `[前の]線/弧の途中につながる` | `connected partway along the previous line/arc` |

角括弧とスラッシュはここでの選択肢の説明であり、本文には書かない。英語の`connects to`・`connects partway along`も同じ有限文法に含まれ、`the`・`previous`の省略も受ける。指定しない現在側は始点のままである。自由線を先行対象にする通常DDLの句は `前の形につながる`を使い、自由線の途中は選ばない。

数値位置は関係のために動かさない。必要な移動と衝突すれば、関係だけを診断付きで外す。Touchingで寸法・大小（普通を含む）や角度を明示したときも固定条件となり、接触のために勝手に伸ばしたり回したりしない。MacroのEmitで運べる関係は沿う・切る・触れる・つながる・触れない・間にで、載る・中に・重なる・横切るの4語をEmit内部へ広げない。Macro全体や組全体の鏡写しは、本文の外部関係として別に扱う。

鏡写しは、対応するprimitiveの列と個体数、弧形、辺数が一致し、一つの剛体姿勢で内部の配置まで対応するときに成立する。二つの基準点が同じで軸が決まらない場合も不成立になる。単独図形で現在側の寸法を省いた場合は先行の幾何を受け取れるが、明示した寸法・大小・比率・角度、組やMacroの内部形は固定条件として検査する。

## 5. 複雑な DDL 50例

各例は、それだけで入力できる独立した複数文のDDLである。日本語のブロック全体、または対応する英語のブロック全体をコピーして使う。全50例を標準語彙と通常文法だけで構成し、登録プラグインは必要としない。題とねらいは説明なので、DDLの入力欄には入れない。

数値の位置は画面の横・縦それぞれの割合、寸法は画面の短い辺を1とした長さである。キャンバス形式（描く紙）と種はアプリ側で選ぶ。アプリから描くと、新しい DDL の先頭には紙の比の宣言（「画面比1:1。」など）が入る。同じ例でも形式や種によって細部は変わる。これらは新たに描くための例であり、保存済みSVGの見た目を現行エンジンで再現した記録ではない。

### 5.01. 三つの寸法で組む画面

ねらい：半径、幅と高さ、一辺を使い分け、三つの図形を数値の位置へ置く。

日本語DDL：

```text
紙。
背景を白で埋める。
画面の横0.25、縦0.3の位置に、半径0.1の赤の空の円を1個置く。
画面の横0.7、縦0.3の位置に、幅0.25、高さ0.15の青の塗りの楕円を1個置く。
画面の横0.5、縦0.7の位置に、一辺0.2の黒の空の四角を1個置く。
```

英語DDL：

```text
Paper.
Fill the background with white.
Place one red empty circle radius 0.1 at horizontal 0.25, vertical 0.3.
Place one blue flat ellipse width 0.25, height 0.15 at horizontal 0.7, vertical 0.3.
Place one black empty square side length 0.2 at horizontal 0.5, vertical 0.7.
```
