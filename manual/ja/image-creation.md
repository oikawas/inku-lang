# 画像の作成方法

inku は、短い言葉から抽象的なベクター画像を作るアプリケーションです。入力した言葉は、`解釈`、`中間フィルタ`、`構造化`、`レンダリング` の順に処理され、最後に SVG 画像として表示されます。

```
記述  ->  正規化DDL  ->  拡張DDL  ->  JSON Score  ->  SVG
```

同じ記述でも、モデルや揺らぎによって少し違う出力になります。inku ではこの違いを失敗ではなく、演奏ごとの違いとして扱います。

## 1. ログインする

1. ブラウザで inku の Web UI を開きます。
2. `ユーザー名` と `パスワード` を入力します。
3. `ログイン` を押します。

ログイン後、画面左側のレールから設定、言語、テーマ、プロフィール、ログアウトを操作できます。

## 2. まず 1 枚描く

1. `記述` タブを開きます。
2. `指示` 欄に短い文章を入力します。
3. 必要なら `キャンバス比率`、`モデル選択`、`色カタログ` を選びます。
4. `描画する` を押します。
5. 描画が終わると、右側のキャンバスに画像が表示されます。

最初は、何を描くかを細かく指定するより、「何が気になっているか」を短く書くと扱いやすくなります。

例:

```text
山の向こうに月が昇る
```

```text
青いクレヨンの線がゆっくり波打つ
```

```text
白い余白に、赤い小さな円を右上へ三つ置く
```

## 3. 書き方の基本

安定した画像を作りたい場合は、1 行に 1 つの視覚指示を書くと解釈が安定します。

基本形:

```text
色 + 大きさ + かたち + 数 + 場所 + 動き
```

例:

```text
背景を白で塗りつぶす。
青い細い線を左下から右上へ三本引く。
赤い小さな円を右上に三個置く。
```

使いやすい語彙:

| 種類 | 例 |
|---|---|
| かたち | 円、楕円、三角、四角、線、弧 |
| 色 | 白、黒、青、赤、緑、灰 |
| 場所 | 上、下、中央、左端、右端、上端、下端、中心、隅 |
| 動き | 置く、並べる、埋める、散らす、引く |
| てざわり | 鉛筆、ペン、ロットリング、クレヨン、チョーク、細筆、太筆、縄 |
| つらなり | 実線、破線、点線、一点鎖線 |
| ゆらぎ | 細かく、大きく、ゆっくり、速く、揺れる、波打つ、震える、滲む |

## 4. Saijiki を使う

`歳時記` は inku の語彙辞書です。

1. `歳時記` ボタンを押します。
2. 使いたい語彙を探します。
3. 語彙をクリックすると、入力欄のカーソル位置に挿入されます。

歳時記は自動補完ではありません。書く前に候補へ引っ張られないよう、必要なときだけ見に行く辞書として設計されています。

## 5. 解釈を確認する

描画後、`解釈 (正規化DDL)` に inku が入力文をどう読んだかが表示されます。

- 入力文: 人間が書いた言葉
- 正規化DDL: コア語彙へ整理された描画指示
- JSON: レンダラーが読む機械向けの楽譜
- 描画: SVG として演奏された結果

意図と違う画像になった場合は、画像だけでなく `解釈` を見ます。例えば「佇む」が意図と違って読まれた場合は、次の記述で「中心に置く」「細かく揺れる」のように具体化します。

## 6. DDL を直接編集して再描画する

1. 描画後、`解釈 (正規化DDL)` の `編集` を押します。
2. DDL を修正します。
3. `完了` を押します。
4. `DDLから描画` を押します。

入力文からやり直すのではなく、解釈結果だけを調整したいときに使います。

## 7. キャンバス比率を選ぶ

`キャンバス比率` から、正方形以外の比率を選べます。

主な比率:

| ID | 用途の目安 |
|---|---|
| square | 正方形 |
| golden | 黄金比 |
| a4 | A4 |
| b4 | B4 |
| wide | 横長 |
| vertical | 縦長 |
| byobu | 屏風状の横長 |

座標は常に 0.0 から 1.0 の比率で扱われるため、キャンバス比率を変えても記述の考え方は同じです。

## 8. 色カタログを選ぶ

`色カタログ` では、抽象色名を実際の色へ変換するカタログを選びます。

記述では `赤`、`青`、`灰` のような基本色を書きます。実際の `#RRGGBB` はサーバー側の色カタログで決まります。履歴には使用した色カタログと実色の対応も保存されます。

## 9. 画像を書き出す

描画後、`エクスポート` から保存できます。

| 形式 | 用途 |
|---|---|
| SVG 表示用 | Web 表示や PNG 生成の元データ |
| SVG 編集用 | Illustrator / Affinity などで編集しやすいレイヤー構造 |
| SVG 互換優先 | 汎用的な SVG 受け渡し |
| PNG | 指定サイズのラスター画像 |

SVG はベクター画像なので、紙、壁面、画面などへ拡大しても扱いやすい形式です。

## 10. 履歴を使う

生成した画像は履歴に保存されます。

- 下部の履歴ストリップから過去の画像を選べます。
- スターで重要な画像をマークできます。
- 履歴管理から検索、スター絞り込み、削除、ごみ箱、復元ができます。
- 履歴を選ぶと、入力、解釈、JSON、SVG、モデル、色カタログ、キャンバス比率を確認できます。

履歴 DB が正本です。ファイル出力は再生成可能な副産物として扱われます。

## 11. バッチで複数枚作る

1. `バッチ` タブを開きます。
2. 1 行に 1 指示で複数行を入力します。
3. 必要なら `描画ごとに色カタログをランダム選択` を有効にします。
4. `描画する` を押します。

例:

```text
山の向こうに月が昇る
夜の霧が広がる
青いクレヨンの線がゆっくり波打つ
```

処理中は現在行、進捗、経過時間、トークン数、現在の解釈が表示されます。

## 12. デモを使う

`デモ` タブでは、シードフレーズから短い指示文を生成し、その指示で描画を繰り返します。

設定項目:

| 項目 | 内容 |
|---|---|
| DBに保存 | デモ生成結果を履歴 DB に保存する |
| ファイルに保存 | SVG / JSON / PNG などの artifact を保存する |
| 指示文生成モデル | デモ用の指示文を作るモデル |
| シードフレーズ | 指示文生成の起点 |
| 表示間隔 | 次の描画までの秒数 |
| 色カタログランダム | 描画ごとに色カタログを変える |

気に入ったデモ画像は `現在の描画をDBに保存` で履歴へ追加できます。

## 13. CLI で画像を作る

CLI は Web UI と同じ API を使う操作ツールです。

```sh
cd cli
uv run inku-cli --base-url http://127.0.0.1:8100 login -u admin
uv run inku-cli paint "青い線が左下から右上へゆっくり波打つ" -o out --png --save-history
```

複数行のファイルから作る場合:

```sh
uv run inku-cli batch -f prompts.txt -o out --png --continue-on-error
```

履歴を見る場合:

```sh
uv run inku-cli history --limit 20
```

## 14. うまく描けないとき

| 症状 | 対処 |
|---|---|
| 意図と違う | `解釈` を見て、場所、数、かたち、素材を具体化する |
| 画像が単調 | てざわり、ゆらぎ、配置、色を 1 つだけ足す |
| 要素が多すぎる | 数を明示する。例: `三本`, `十二個` |
| 生成が遅い | モデル設定を軽いモデルへ変える、またはしばらく待つ |
| エラーになる | 入力を短くし、1 行 1 指示に分ける |

感情語より、観察できる物理語を使うと安定します。

避けたい例:

```text
美しく優雅に強い絵を描く
```

改善例:

```text
黒い太筆の線を中央に一本置く。
灰の円を周囲に七個、少しばらつかせて並べる。
```
