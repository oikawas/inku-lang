# マニュアル改訂履歴

この履歴は`manual/`配下の利用・運用文書の改訂を記録します。製品機能そのものの詳細な変更履歴は`SPEC.ja.md`を参照してください。

## 2026-08-06 — v2.11.1未リリース基準（Web Build 856）

版を名乗る13箇所をv2.11.1（Build 856）へ更新した。本文の説明は変えていない。

- `制限値`タブの九つの数は、DBバックアップタブと同じ**`−`／`+`つきの入力**になった。**変更の仕方は変わらない**（管理UIか`inku-cli config update`）ので、`サーバー設定方法`5.1の記述はそのまま通用する。

## 2026-08-05 — v2.11.0未リリース基準（Web Build 854）

v1.85（Build 564）から51版ぶんの追随。日英とも同じ章構成へ揃えた。

- 版を名乗る11箇所をv2.11.0（Build 854）へ更新した。`manual/README.md`だけv1.82（Build 563）とさらに古かった。
- `画像の作成方法`を現行Web UIへ全面改定した。**写生（Stage 0.5）**、**変奏**、**暴れる**、色カタログの`記述から自動選択`、**UIモード**、推敲マーク、`再現`、コンタクトシート、アニメーション書き出し、ハッシュ下位4桁での検索、設定タブ10種を追加した。
- 章構成を15節から20節へ広げた。**`言語比較`は現行UIに無いので落とした**（`language_variation`は保存済み作品の派生種別としては残る）。
- 用語を現行UIへ揃えた。`正規化DDL`は`指示書（正規化DDL）`、`生成する`は`描画する`、右側タブは`作品`と`系譜`、生成情報は`詳細`／`プロンプト`／`JSON`。
- キャンバスを6種から**9種**（Square / Golden / A4 / B4 / Pillar / Oban / Wide / Byobu / Vertical）へ直した。
- `inku-cliリファレンス`へ**未記載だった6コマンド**（`plugin`／`reference`／`colophon`／`user`／`group`／`config`）を足した。
- `paint`／`batch`の旗を用途別の表にした。写生3、変奏2、`--wild`、`--catalog-mode`、`--interpretation-seed`ほか**26の旗が未記載だった**。**旗を書かなければサーバー既定で描かれること**と、**サーバー既定とWeb UI既定が違うこと**を明記した。
- `サーバー設定方法`へ**未記載だった19の環境変数**を足した。廃止済みの記載は無かった。層とプラグインの節（2.5）を新設し、providerを2.6へ送った。
- 制限値の節（5.1）を新設した。九つの値、既定、丸めの規則を載せた。**環境変数は初期値を与えるだけで、以後はDBの設定が正本である**ことを明記した。
- render hashを`rh2:`から**`rh3:`**へ直した。canonical payloadの内訳と、鍵名を改名してはならない理由を足した。
- パイプラインの表へStage 0.5、プラグイン展開、coerceを足した。写生文が三つの消費者へ届くこと、`sketch_state`の値が無いことは`off`ではないことを明記した。
- `アプリケーションインストール`の前提を**Python 3.10以上から3.12以上**へ直した（`requires-python`は`>=3.12`）。受け入れ確認の項目を現行UIへ揃えた。
- `AI自律運転・テスト用リファレンス`の`--kind reading`の説明を直した。**Stage 1.5ではなくStage 1**で、Stage 1.5はLLMではない。`derivation_kind`の対応も足した。
- 同文書へ「沈黙する送り手に注意する」（0.8）を足した。**変奏は2つの旗が揃ったときだけ効き、旗を渡したことは成功の証拠にならない**。
- 日英の混ざった壊れた一文を直した（`refine perform`の説明）。
- 環境変数テンプレートへ、描画の並列度、段ごとのhard timeout、認証方式、プラグイン置き場、学習語の保存先、Redisを足した。

## 2026-07-22 — bootstrap adminの前提を明記

- inkuにセルフサインアップが無いこと、bootstrap adminなしで空のDBを起動するとログイン手段が無くなること、passwordを設定して再起動すれば復旧することを「Server Configuration 2.2」と「Application Installation 7」に追記。
- `INKU_BOOTSTRAP_ADMIN_PASSWORD` の空文字が未設定と同じ扱いになること（初回作成後は空欄でも行削除でも同じ）を追記。
- 「Application Installation 16 コンテナ実行」に、composeが値の無いまま起動を拒否することを追記。
- 環境変数テンプレートのbootstrap admin節にも同じ注記を追加。

## 2026-07-15 — v1.85未リリース基準（Web Build 564）

- 全公開APIを権限に応じて操作できる inku-cli api と全コマンド一覧を追加した。
- Composeによる非root API、production Node Web、永続data volumeの導入手順を追加した。従来の開発構成は維持する。
- request body上限、login rate制限、CORS、Renderer同時実行上限、Idempotency-Keyを管理者向け設定へ追加した。
- 履歴のtrash確認、系譜tombstone、再送時の二重保存防止、user scopeを明記した。
- 英語UIのTitle Case統一とiPad幅の表示基準を反映した。

## 2026-07-15 — v1.82未リリース基準（Web Build 563）

全面改定。

- `画像の作成方法`を現行Web UIへ合わせ、指示文言語の自動判定、色カタログ／モデル／キャンバス操作、正規化DDL編集を更新した。
- 推敲の`調整`、`モデル比較`、`言語比較`、言葉による決定的なタッチ変更を追加した。
- 生成情報の`詳細`／`プロンプト`／`JSON`、Stage別言語、seed、hash、derivation metadataを追加した。
- 作品系譜、中間作品、通常履歴への昇格、近い作品、履歴管理の`時系列`／`系譜ごと`を追加した。
- `アプリケーションインストール`をlockfile、migration前backup、systemd参照構成、受け入れ確認、rollbackを含む手順へ全面改定した。
- `サーバー設定方法`を設定境界、現行環境変数、DB migration、四つの同一性、認証scope、言語解決、Renderer再現性、backup、監視、security基準へ全面改定した。
- 環境変数、systemd、logrotateの付属テンプレートを現行の参照構成と権限方針へ揃えた。
- 日本語版と英語版を同じ章構成と機能境界へ統一した。

## 改訂規約

- `SPEC.ja.md`を製品仕様の正本とする。
- マニュアル変更は日本語版を先に行い、英語版へ同じ意図を反映する。
- UI挙動を変更した場合は対象Web Buildを記録する。
- host名、IP、実ユーザー名、秘密、ローカルservice情報はマニュアルへ記録しない。
