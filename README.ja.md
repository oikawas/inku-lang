# inku

**視覚をデザインするために、万人が使える、小さく限定的な言語**

`inku` は、短く、誰でも書ける短い記述から、抽象的なベクターグラフィックを生み出す、記述ベースの描画言語です。三つの伝統に根ざしています。

- **Sol LeWittの指示書きによるアート** — 記述そのものが作品であるという思想
- **盆栽** — 空間や素材への厳格な制約が、表現を制限するのではなく凝縮する実践
- **短歌の形式** — 型が自我を削ぎ、主張ではなく提示が残る

語彙・プリミティブ・座標空間への制約は、限界ではなく、意図を可視化するための道具立てです。

---

## コンセプト

```
記述（自然言語） → 正規化DDL → 拡張DDL → 楽譜（JSON Score） → 演奏（SVG）
人間が書く          Stage 1      Stage 1.5   Stage 2              Renderer
```

記述は永続し、演奏は一回性。出力は都度わずかに異なる——モデルの進化や差異が揺らぎを生み出すことを意図した設計です。
コンピューティングの技術を使いつつ、同じ記述から毎回少し（あるいは大きく）違うものが生まれます。

---

## 例

**記述:**

```
細かく揺れるペンシルの破線が3本、画面を横切る
```

**正規化DDL（第一段階の解釈後）:**

```
ペンシルで 破線を 横に 3本 置く
揺れ: 細かい
```

**JSON Score（第二段階の構造化後）:**

```json
{
  "instructions": [
    {
      "primitive": "line",
      "style": "dashed",
      "from": [0.0, 0.33],
      "to": [1.0, 0.33],
      "weight": "pencil",
      "variation": {
        "amplitude": "fine",
        "frequency": "high",
        "quality": "perlin",
        "dimensions": ["position_y"]
      }
    }
  ]
}
```

レンダラーがこの楽譜を演奏（描画）します——毎回わずかに違う形で。
誰かの指示（歌）を書き換えても良いでしょうし、ベクターグラフィックですから、大きく引き延ばして額に飾っても、壁にペイントしても良いでしょう。物理世界でのサイズの制約は有りません。

## アーキテクチャ

inku は **Stage 1 / Stage 1.5 / Stage 2 / Renderer** のパイプラインを採用しています。

1. **Stage 1: 解釈** — 記述者の母語で書かれた自由な記述を読み取り、コア語彙のみで構成された正規化DDLに変換する
2. **Stage 1.5: 中間フィルタ** — 決定的な変換器として、数学・幾何・音楽・絵画技法の候補を選択的に加え、動的な焦点や余白を調整する
3. **Stage 2: 構造化** — 正規化DDLを妥当な JSON Score に変換する
4. **Renderer: 演奏** — JSON Score を SVG として描画する

この分離により、自然言語の読解、表現の拡張、構造化、描画をそれぞれ独立して調整できます。API 経由のモデル、ローカルLLM、NVIDIA NIM などを段階ごとに選択できます。

## コア語彙（歳時記 / Saijiki）

参照語彙辞書は **歳時記（Saijiki）** と呼びます。俳句の実践から借りた言葉で、季語を集めた書のこと。常に開くものではなく、必要なときに参照するものです。

| カテゴリ（日） | カテゴリ（英） | 語彙 |
|---|---|---|
| かたち | forms | 円、楕円、三角、四角、線、弧 |
| てざわり | touches | ペン、鉛筆、ロットリング、細筆、太筆、クレヨン、チョーク、縄 |
| うごき | motions | 置く、並べる、埋める、散らす |
| ばしょ | places | 上、下、中心、端、隅 |
| つらなり | continuity | 実線、破線、点線、一点鎖線 |
| ゆらぎ | movements | 細かく、大きく、ゆっくり、速く、揺れる、波打つ、震える、滲む |
| いろ | colors | 白、黒、青、赤、緑、灰 |
| かたむき | rotation | 水平、垂直、斜め、回転 |
| わりあい | proportions | 縦長、横長、全幅、半幅、半円、上弦、下弦、三日月 |

物理的・観察的な言葉のみが許容されます。「美しく」「繊細に」「激しく」といった感情的な評価はコアに含まれません。

## 設計原則

1. 記述は人間が読める——自然言語と記述言語の中間に位置する
2. 揺らぎは仕様であり、バグではない
3. 感情語彙を排除し、物理と運動の語彙を採用する
4. 固定のキャンバスを持たない——座標は 0.0〜1.0 の比率で、あらゆる媒体にスケール可能
5. 出力は静止画——動くのは見る人であり、画像ではない
6. 入力は制約付きDSLであり、完全な自由形式ではない

設計の詳細な根拠は、日本語正本の [SPEC.ja.md](SPEC.ja.md) を参照してください。

## 機能概要

Web版は稼働中です。現在対応している主な機能：

- **多段パイプライン** — Stage 1 / 1.5 / 2 / Renderer。各段階のモデル、トークン数、実行時間を確認可能
- **プリミティブ** — 線・円・楕円・弧・四角・三角。素材、色、スタイル、揺らぎ、回転、配置を指定可能
- **配置** — 横並べ・縦並べ・放射状・散布に加え、波打つ軌跡、斜めの帯、上から下、右半分などの path 指定
- **素材表現** — 鉛筆、ロットリング、クレヨン、チョーク、筆、縄などを、線幅だけでなく texture filter・粒・副線で描き分ける
- **安全な描画** — 不可視色、過密、重複 instruction、空 instructions、長時間 LLM 応答を補正・fallback
- **バッチ / デモ / CLI** — Web の単発・バッチ・デモ描画に加え、`inku-cli` からログイン、描画、バッチ生成、ベンチ出力が可能
- **履歴** — DB を正本としてユーザー別に保存。ページング、検索、スター、サムネイル、モデル・色カタログ・トークン情報を保持
- **UI** — 歳時記パネル、JSON/プロンプト表示、ライト/ダークモード、折りたたみ可能な履歴エリア、ズーム/パン対応キャンバス

## ステータス

現在の実装:

- **Web版** — 稼働中（Python FastAPI + SvelteKit、ローカルまたはサーバーで動作）
- **CLI** — `cli/` 以下に独立プロジェクトとして実装。API 経由でログイン、描画、バッチ生成、ベンチ評価を実行
- **Android アプリ** — Pixel 9 で動作確認済みの旧DDL向けデモはあるが、現在の inku-lang 仕様に対応した Android 版は未準備

## エコシステム

関連パッケージは `inku-` プレフィックスで統一します。

- `inku-core` — コアライブラリ
- `inku-saijiki` — 語彙辞書
- `inku-nature` — Nature プラグイン（風、さざ波など）
- `inku-web` — Web UI 実装
- `inku-android` — Android 実装
- `inku-cli` — コマンドラインツール

---

## 言語バージョン

**日本語版**と**英語版**の inku は作者が維持します。他言語の実装は、OSS として各言語話者の貢献を歓迎します。

内部のJSON Score層は言語非依存（英語キーで統一）です。翻訳が必要なのは、記述の表層部分のみです。
