# inku 運用・利用マニュアル

このディレクトリは、inkuを初めて使う人が作品を作成できることと、システム管理者がアプリケーションを展開・運用できることを目的にしたマニュアルです。Web画面の操作説明はv2.15.329（Web Build 1405）を基準にしています。製品仕様の正本はリポジトリ直下の`SPEC.ja.md`です。

## 対象読者

- 画像作成者: Web 画面または CLI から、短い言葉を入力して SVG / PNG 画像を作成する人
- システム管理者: サーバーへ inku をインストールし、API、Web UI、DB、ログ、バックアップ、AI 接続を管理する人

## DB バックアップと片付け

管理者は DB バックアップの設定で、検証済みの手動・定時バックアップ後に作品へ結び付かない文書を片付けるか選べます。既定では有効で、最後の更新から 7 日の猶予があります。猶予は 1〜365 日に変更できます。作品や子、実行中の持ち手がある文書は残ります。復元前の安全バックアップでは片付けません。

macOS・iPhone・iPad のアプリでも、DB バックアップの設定から、検証済みのバックアップ後に未保存の実行を片付けるか選べます。既定で有効、猶予は 7 日で、1〜365 日に変更できます。保存した作品や実行中の記録は残り、復元前の安全バックアップでは片付けません。
